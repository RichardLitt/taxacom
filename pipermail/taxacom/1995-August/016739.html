The recently released version of CONFOR, version 2.15, has a bug affecting the
processing of uncoded controlling characters. If you experience problems in
this area, an interim solution is to explicitly code the controlling character
e.g. 10,U or 10,- (as appropriate). Alternatively, a revised version of the
program is available as self-extracting file, CONFOR at .EXE, at the ftp site
spider.ento.csiro.au in the directory delta/test. To decompress the file, type
CONFOR@
