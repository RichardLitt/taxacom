> The tables should be fairly straight forward with taxa being in "name_usage" and names in "name".
> A simple join to get the core properties for a taxon would be this sql:
>
> 	select u.id, parent_fk,n.scientific_name, rank, status, p.citation as publlishedIn from name_usage u join name n on
> name_fk=n.id left join citation p on name_published_in_fk=p.id order by rank limit 100;
>
