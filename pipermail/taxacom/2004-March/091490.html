We had an interruption in Taxacom mail service for some period recently
due to the mail list server going into a 'HOLD' state, which happens when
some exceptional condition occurs. The mail server goes into 'hibernation'
until it receives further instruction. Think of the Mars rover.

We'll keep an eye on it.

If you received a large number for mail messages in the last day or two,
that was due to the server releasing the held mail.
