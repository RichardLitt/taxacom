2010 
Biodiversity Informatics Programmer.


To upgrade the heavily used, frequently updated, but computationally  
static resource, Angiosperm Phylogeny Website (http://www.mobot.org/ 
MOBOT/Research/APweb/), to a dynamicplatform that will serve  
structured plant diversity data via a website, web services, and  
semantic queries, and will integrate dynamically with phylogenetic  
and other biodiversity databases, and with visualization tools,  
particularly for education and outreach.  The data served will  
include phylogenies, taxonomies, synonyms, images, literature, and  
extensive character data.  The core technologies will be: web  
interface programming using perl and shell scripts in a GNU/Linux and  
Apache environment, Javascript, XML manipulation, RDF data and  
ontology management and query. APweb will allow iPlant to include new  
data being served by this dynamic platform in the development of the  
Grand Challenge Projects. Success criteria will include keeping a  
site that for one view is similar to the current site, but allows  
other more focused views of the information contained.


Salary: $55,000 p.a. Time: One year, extendable for six months.   
Location: St Louis.
