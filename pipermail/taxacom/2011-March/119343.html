Victor,

NaviKey is based on DELTA and is a Java key, you can see an example key 
here:
http://botu07.bio.uu.nl/arisaema-l/NaviKey/index.html

It does not yet support images, but I think the project is open to be 
developed more by others.
You will find the needed links in the example.
