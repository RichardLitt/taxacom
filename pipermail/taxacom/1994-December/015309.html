1994 
A new version of the Taxacom listserver archives is now available on
the Biodiversity and Biological Collections Web Server at the URL:
http://muse.bio.cornell.edu/archive/   The individual messages have
been run through the hypermail utility program which produces sorted
HTML versions of all messages.  Index pages sorted by thread, date,
subject or author are all available.
