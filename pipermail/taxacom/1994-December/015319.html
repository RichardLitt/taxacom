> From Susan Mazer (mazer at lifesci.lscf.ucsb.edu)
>
> Is Delta now available for use on Macintosh computers, or only for DOS?

The DELTA programs will run under DOS and Windows emulators on a Mac. We
recently did some tests on a Power Mac 7100/66AV with 16MB of RAM. The speed in
DOS/Windows emulation is roughly 15% that of a 50MHz 486. The substantially
lower speed is no problem for most INTKEY (interactive identification)
operations, which complete almost instantaneously. However, the time taken for
operations which involve scanning the whole data matrix might be regarded as
inconvenient. Here are some times, in seconds, for John Lawrence's
beetle-larvae data (180 characters, 385 taxa). The native DOS/Windows times are
in parentheses.
    Check the main DELTA data files (CONFOR, DOS): 167 (25)
    Find the `best' character (INTKEY, DOS): 145 (18)
    Find the `best' character (INTKEY, Windows): 120 (18)
However, you don't need to wait for the `best' calculation to complete before
choosing a character. Also, this option is mainly used towards the end of an
identification, when it runs much more quickly.
