> Perhaps Biota output could be fed into a mail merge template in
> Microsoft Word, allowing for better control of fonts, italics, etc. Has
> anyone tried this?

I've used a Microsoft Access table reading into a MS Word mailmerge
document. The latter can really be quite elaborate, not only with fonts,
but double columns to save paper, text flow controls to keep labels from
straddling page breaks, if/then/else controls that inspect fields in the
database, etc. It works well.

Obviously it's best to set up your own, customized mailmerge document,
because of inevitably different database structures, field names, and
house styles for labels.
