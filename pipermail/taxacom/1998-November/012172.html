Once again, I thank Jacques Melot, this time for bringing to
my attention a portion of the ICBN of which I was unaware.
However, this clause changes nothing. It applies only to
cases in which the requirements for validation were incomplete.
That makes it irrelevant. For a name published in 1906, all
that is required is the name plus a description. The description
does not have to be a good description or a complete
description. If the author described the stem and the leaves
and said "To be continued," i.e. "Flowers and fruits to
be described in next issue," this does not negate the fact
that she already described the stem and leaves. This is
enough.
