Dear Listers,
   
  Under what Code are we making these various arguments?  Since the zoological Code doesn't concern itself with catagories above the family-group, entities like phyla are outside those rules.  Higher categories are not typified by members of the next lower category (what class is the type of the phylum Mollusca?), so there is not even a taxon sine qua non to lend definition to them.  And even if the zoo code were enlarged upward to include higher categories, it could scarcely govern howt bacteriologists deal with with their organisms.  Some listers are making implicit arguments from priority -- but even that's not a written rule at this level.  Are we creating an object lesson for the desirability of a BioCode?
