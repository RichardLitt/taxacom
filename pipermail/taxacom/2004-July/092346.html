Specify Collections Management Software -- Now with DiGIR Support


The Specify Software Project would like to announce the availability of
Specify 4.6, now downloadable from the Specify Software web site:
http://specifysoftware.org.

Specify 4.6 includes a DiGIR installation package that contains all the
software components you will need to enable your Windows 2000 or XP
database machine as a DiGIR provider. The Specify DiGIR package for
release 4.6 handles the setup for a DiGIR server, a web server and the
PHP language; it will guide you though the process of configuring these
components on your database workstation or server.

With release 4.6, Specify collections can now serve XML-structured
specimen records using the DiGIR protocol to taxonomic discipline
networks such as MaNIS, HerpNet, and Fishnet, to mapping and modeling
applications such as Lifemapper, to biogeographic data warehouses such
as OBIS and to the Global Biodiversity Information Facility portal.

Our next release Specify 4.7, scheduled for late 2004, will be focused
on usability enhancements to the Windows interface.

Make your museum or herbarium part of the burgeoning global research
infrastructure with Specify 4.6 and DiGIR.
