                      Softwares for taxonomists                    9/26/04
Hideaki Sugaware asked me to post his message on Taxacom:

I would like to introduce e-Workbench of databasing, identificaiton
and classification mainly for microbes, namly, InforBIO, G-InforBIO
and O-InforBIO. InforBIO is an integrated data management and
analysis sytem including: numerical taxonomy and phylogenetics,
probabilistis identification and identification by decision tree and etc.

InforBIO is also able to identify key phenotypic character(s)
that can discriminate clutsters suggested by phylogenetic
analysis based on sequence data.

G-InforBIO is for the comparative genomics. O-InforBIO is a tool
to make multiple databases made by InforBIO open to the Internet
in an integrated database.

The InforBIO suite uses XML for their main file and can export/import
EXCELand CSV fiels. It is written by JAVA and can be run on
WINDOWS 2000/XP, Macintosh (OS X) and linux.

The download site is: http://lilium.genes.nig.ac.jp/index_e.html
