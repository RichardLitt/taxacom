1995 
Building on a fifteen-year history of botanical database development, the
Missouri Botanical Garden is revising its comprehensive information
system, TROPICOS. The new system incorporates the functionality of
TROPICOS with the features of relational database technology.

Visit the web site at

http://db.mobot.org

The web site includes a description of the project, demonstration screens,
and a WWW interface to a prototype database.  The WWW interface
accommodates SQL queries through a forms interface.

Those familiar with TROPICOS will notice dramatic changes in the user
environment.  The new system is Windows-based, providing a graphical user
interface to the powerful features of the database.  Because the new
system resembles other Windows applications, Windows users will find it
quite intuitive.  Context-sensitive help screens will add to the system's
user-friendliness.  Additionally, WWW access to the database provides
Internet users with a familiar interface.
