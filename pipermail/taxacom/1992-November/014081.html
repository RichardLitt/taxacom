Thanks to all who offered advice on access to the geographic name server.
The trick is to specify port 3000 in addition to the host name
martini.eecs.umich.edu.  From many machines with telnet access this is done
by adding 3000 (no dot) after the telnet command thus:
    telnet martini.eecs.umich.edu 3000
Reportedly using telnet from a Vax another form must be used:
    telnet martini.eecs.umich.edu/port=3000
