Only after the last tree has been cut down,
only after the last river has been poisoned,
only after the last fish has been caught,
only then will Platypus finish drawing a dialog box.

           MY PERSONAL EXPERIENCE.

To be serious, you should use no less than a Pentium 100 (or higher)
with 16 or, better, 32 Mb RAM to run Platypus. Otherwise you will
see 'how Windows work'. A dialog box on 486DX 66 MHz 8 Mb RAM takes
several minutes. Starting a search operation you can start a coffee-break
as well. I asked my programist friend (he is also a hydrobiologist)
why Platypus is so slow. He told me that it is an usual disadvantage
of visual-basic applications and that being written in Delphi it will
run faster. The same problem could be solved using a more powerful
computer.

However, a booklet on Platypus is very promising. I will try again after
some structural upgrade.
