Dear Taxacom members,

We like to learn about the possible relational database programs available
for living collections, beside BG-Base.

Features needed:
- relational concept with 'Name', 'Accession' and 'Plant/location' levels
- possibility to of an literature database (included)
- GIS mapping system for locating trees in Arboreta etc.
- multi user on LAN (record locking)
- Windows '95 interface preferred

I would like to hear about experiences in other Botanic Gardens.

Eric
