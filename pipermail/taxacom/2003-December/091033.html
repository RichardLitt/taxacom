Dear All,

TREEFINDER has now an utility to compute rate profiles along sequence
alignments, which might be useful if one is investigating selective forces
on DNA sequences.

Another new tool can calibrate phylogenetic trees in time using Michael J.
Sanderson's nonparametric rate smoothing method (NPRS). It outputs a
chronogram and also a ratogram with estimates of absolute evolutionary rates.

Since October, there is also an improved support for bootstrapping and tree
manipulation.

Finally, the new version comes with a more informative documentation on the
TL programming interface.

As usual, the new version is available at   www.treefinder.de   and runs on
Windows, Linux and MacOS X.

Cheers,
