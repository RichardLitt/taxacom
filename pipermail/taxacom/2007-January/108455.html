If Brazil is really serious about their own resources, it ought to set up a
proper monitoring program to watch the logging and including its related
biodiversity. In order to do so, the collecting permissions for scientists
to describe what is in the areas to be logged should be issued at the same
time, and the logging companies should be required to describe the diversity
of the forests within a reasonable scheme.
