	New Web Interface for the AAU Herbarium Database
	 
	The web interface to the AAU Herbarium database has been updated
and rewritten in php.  This means that the system now is accessed via
the normal server port and those who might have experienced problems
accessing the database before due to home-institution security systems
preventing browsing on more than one server channel should no longer
have such difficulty.
	 
	Access the new pages via www.aubot.dk
	 
	It is now possible to specify a search on specimens with images
only.  AAU is the middle of a general specimen digitisation program. 
	In addition hit lists can now be sorted by any field by clicking
the column header.  This might, however, still be very slow in some
cases
	- we are working to improve indexing systems to speed up the
process.
	 
	We welcome any notification about problems experienced with the
new interface or general comments.
