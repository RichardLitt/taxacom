Geotrans 3.1 is another useful program that includes transformation of 
co-ordinates, either individually or in text files for bulk translation. 
Setting up the input file is a little fiddly, but once you have it set 
up, you can use it for as many batches of co-ordinates as you want.

http://earth-info.nga.mil/GandG/geotrans/

There are versions for Windows and Linux/Unix.
