The Trichoteleia case is actually an interesting one, because the data have already been compiled in the Hymenoptera Online Database:

http://hol.osu.edu/index.html

Try this experiment. Go to this webpage and type 'Trichoteleia pauliani' into the Search box. Check out the information available once the search returns a result, and notice how long it takes to see that information.

Now go to the GBIF data portal and search for this species. Is it easier/harder, slower/faster to get the same info than through the hymenopterists' effort?

Both of these resources are online and free. Which would you prefer to use? (Do I hear you saying 'But that depends on the user and what information they want!' Hmmmmmmmm)
