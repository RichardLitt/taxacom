1996 
I am writing to announce the availability of the Jepson Place Name Index
(JPNI) on the World Wide Web through the home page for the University and
Jeposn Herbaria (URL: http://ucjeps.herb.berkeley.edu).

The JPNI contains approximately 41,000 place names found on botanical
collection labels. Over a period of approximately 50 years, staff and
associates of the Jepson Herbarium have reserched these place names using
maps in libraries and archives at Berkeley and elsewhere. The JPNI has been
maintained by the Jepson Herbarium as a card file for reference purposes.
The SMASCH project has entered all the data from these cards into the SMASCH
database. SMASCH staff added the feature type for each locality using the
definitions contained in the US Geological Service Geographic Names
Information System.

A form-based interface on the WWW allows searches by place name (case
insensitive, SQL wild-cards recognized) or county. A complete record from
the SMASCH database is returned for each record matching the search. A
complete record contains the place name, county, feature type, a more
detailed description of the location of this place name on one or more maps,
and the map source.

The staff of the Jepson Herbarium and the SMASCH project hope that you find
this a useful resource.
