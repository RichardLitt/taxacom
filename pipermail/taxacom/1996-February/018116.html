DIANA is an interactive MS-Windows software management system for editing
DELTA data and directives files and running DELTA programs. It is available
by gopher or anonymous ftp from the following Internet hosts.

     Host                   Directories
     --------------------   ----------------------------
     muse.bio.cornell.edu   /pub/delta/diana
     ftp.ento.csiro.au      /delta/diana

or via WWW from
     http://muse.bio.cornell.edu/delta/

The distribution package consists of a text file Dianaw.1st, containing this
information about downloading the programs, and a self-expanding file
dianaw at .exe, containing the programs and documentation. All the files must be
transmitted in binary mode, set by the ftp command `binary'. (Failure to do so
will result in the error message `HeaderC Error' when the .exe files are run.)

Copy the file DIANAW at .EXE into the directory C:\DELTA on your MS-DOS computer,
and expand it by entering DIANAW at . Start the program by double-clicking on the
DIANA for Windows icon from your DELTA Program Group. The Windows Write file
DIANAW.WRI contains details of installation and operation.

Changes
=======

o  The program now calls all the Windows versions of the DELTA programs,
namely CONFORQW, DELFORQW, DISTQW, and KEYQW (plus INTKEY4, as the previous
version already did).

o  A command was added to allow moving the cursor to a specified line number.

o  Several minor corrections and/or modifications were also made in the menus
and the DIANAW.HLP (Windows Help) file.

If you have any suggestions or problems with the software please contact me.
DIANA for Windows is freeware - it may be used, copied, and distributed freely,
provided that no price or fee is charged for it.
