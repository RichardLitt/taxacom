Dear Gary Noonan:

Taxasoft has progams based on DELTA format which are not expensive. A
license to produce the data files, keys, descriptions and can be used for
interactive identification is US $149.

You will be able to produce a binary file that can be used for interactive
identification and that may be distributed together with a freeware program
that uses this binary file for the identification.

A (end)user who only uses the interactive key, does not need a license
on the Taxasoft software! Beside identification, it is possible to view
diagnostic and natural language descriptions, and the original DELTA data
is protected and can't be printed.

Regards Eric.
