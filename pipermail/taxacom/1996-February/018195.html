intended it to go to the lsit:

I've prepared the font in Windows Truetype format (Mac truetype will
follow).  It is available at:

http://www.sci.csupomona.edu/biology/clark/clark.htm#software

or

http://www.sci.csupomona.edu/biology/clark/fonts.htm

The first address includes other biological software, and the second
includes other fonts that are not biological.

It is a "Beta-test" version; it works okay, but I plan to add symbols and
adjust some of the existing ones.

It currently includes female, male, hermaphrodite, virgin (the Mercury sign,
used by entomologists in this sense), annual, and perennial.
