Taxacomers,

HICLAS is a taxonomic database system developed at Michigan State University
(MSU) with funding from National Science Foundation. It is available now. The
X-Window version of this system consists of an intuitiue mouse-based graphical
user interface connected to a Sybase database server at MSU. The interface
allows a user to display and browse hierarchical taxonomic information and
have the capability to display lineage information as well as phylogeny of a
particular taxonomic group.

The X-Window version of HICLAS is available on the Internet. One can access
the system through Open Window interface on a workstation. To obtain HELP
file, please use anonymous FTP to:

ftp://genesys.cps.msu.edu./pub/hiclas/help-file

For additional information please send email to:

hiclas-manager at biosys.cps.msu.edu

Netscape/WWW interfaces of HICLAS will be available soon.
