Someone asked about software for aligning sequences. Ward Wheeler and
David Gladstein's program MALIGN is available via anonymous ftp from
the American Museum of Natural History's ftp server ftp.amnh.org
The files are in the /pub/molecular/ directory. First read the file
read.me.
