Spot on, Ayhan!

I was drafting a reply along the same lines when yours appeared. 

You are correct that, if it is a plant, then the International Code of Nomenclature for algae, fungi and plants applies, and this new species name XX zz would be fine since a name only has priority in the rank in which it was published (see http://www.iapt-taxon.org/nomen/main.php?page=art11 - Art. 11.2).

However, the Code does also RECOMMEND that such infraspecific epithets should be re-used at species level unless already used for a different species in that genus (see http://www.iapt-taxon.org/nomen/main.php?page=art24 - Recommendation 24B.2). So you could have Xx yy, Javier, as long as yy hasn't already been used in genus XX.

If an animal, then the Zoological Code applies and I think the answer would be different - but a zoologist needs to confirm that.

Dear Javier,

My question would be: Are talking about plants or animals?

In ICNafp:

"11.2. A name has no priority outside the rank in which it is published." (see http://www.iapt-taxon.org/nomen/main.php?page=art11)

I know that it sounds unfair, however, you can give a brand-new name to subspecies, if you raising it to species level; and you will get the authorship too, e.g. *Xx zz Javier*.

It is up to you (or to the author): She/he can propose a new combination at species level (this would be wise in my opinion), or give a new name with new authorship (this I called tricky way).

On the other hand, I don't know the situation in Zoological Code. 
Therefore I was asking you whether you talking about plants or animals.

Best wishes,

Ayhan
