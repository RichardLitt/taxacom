Sorry, but the illustration is not the type.  The Code clearly stipulates that it is the individual illustrated that is the type -- Article 72.5.6.

And while we are on this subject, I will stop remaining silent.  Some of the animals that interest me simply disintegrate in preservative.  They cannot be pinned, they cannot be skinned, they cannot be dried (well, maybe they can, but then nothing useful can be done with them).  I take it as part of my function as a Commissioner to represent such animals to the community -- to remind people that toetags or pins cannot be universally applied.  A photo of the living animal that belongs to one of those groups will be far more informative than a jar with some slurry at the bottom.  Moreover, there are deep-sea animals that elude capture but that are repeatedly seen.  Yes, we cannot be certain that all that are spotted belong to the same species, but having a name attached to a photo and some distinguishing features is far superior, in my view, to names such as Big Red, or Species Z, which are what are commonly applied.  This does not begin to deal with marine animals that are too large or rare to be put to death for deposition in a museum.

Finally. At least ONE person here interprets the Code the way the
Commissioners do. Explicit fixation means there can be no ambiguity as
to which specimen is the holotype; the only - I repeat, ONLY - provision
in the Code that allows for the holotype to be something other than a
physical specimen is Art. 73.1.4, which permits authors to explicitly
designate illustrations as types. After 2000, THERE ARE NO OTHER ALLOWED
EXCEPTIONS. Mr. Thorpe seems to be under the mistaken impression that
anything which is not explicitly prohibited (i.e., that the Code does
not explicitly say "unpublished observations cannot be used as the basis
for a holotype designation") must therefore be allowed, but that is NOT
how this works. A database record is UNPUBLISHED, and cannot therefore
be cited as a method of indication for a type specimen. Everything in
the Code assumes that the relevant bits of information are PUBLISHED.
Again, if Hoser had published photos of the type specimens, the Code
would - marginally - have been satisfied, so long as he explicitly
designated those photos AS the types (under 73.1.4). To reinforce my
point, there is ONLY ONE Article in the Code that allows for the use of
unpublished data relevant to type designation, and that is Art.
72.4.1.1, which allows for unpublished information to be used in the
determination as to which specimens are part of the type series - but
this is explicitly ONLY for names published prior to 2000!! Hoser's
names were published AFTER that cutoff, and are therefore NOT eligible
to make use of unpublished data when determining which specimens are in
the type series - accordingly, there is no type series in this case,
because there is no holotype.

There are no other if's, and's, or but's to be applied in this case,
despite what Stephen, Neal, and others are trying to claim; Hoser failed
to meet the conditions for an *explicit fixation* of a holotype, as
required by Art. 16.4.1, therefore his names are unavailable. It might
have worked prior to 2000, but the present edition of the Code,
mercifully, contains provisions that exclude the present case.
