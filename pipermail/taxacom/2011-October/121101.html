Also for completeness, a few families in GRIN recognised subsequent to APG III, mainly in Santalales following Nickrent et al., 2010, except for Stixaceae which is used for some genera unplaced in APG III:

  Amphorogynaceae
  Comandraceae
  Coulaceae
  Nanodeaceae
  Stixaceae
  Strombosiaceae  
  Ximeniaceae

> Dear all,
> 
> Just following up a thread here from last month, I finally got around
> to checking out the GRIN taxonomy as suggested by Tom below, and can
> confirm that (for angiosperms) it does follow APG III with a few
> exceptions, listed below in case these are of interest. In the main the
> latter seem to be small families maintained by some authorities,
> subsumed into larger ones in APG III, though in at least some cases
> there is a note in APG that they may need to be split off with further
> study (and so round we go...)
> 
> Differences between GRIN taxonomy (Sep 2011 download) and APG III:
> 
>   (GRIN => APG III)
> 
>   Chenopodiaceae => Amaranthaceae
>   Valerianaceae => Caprifoliaceae
>   Linnaeaceae => Caprifoliaceae
>   Dipsacaceae => Caprifoliaceae
>   Diervillaceae => Caprifoliaceae
>   Morinaceae => Caprifoliaceae
>   Viscaceae => Santalaceae
>   Erythropalaceae => Olacaceae
>   Aptandraceae => Olacaceae
>   Octoknemaceae => Olacaceae
>   Ledocarpaceae => Vivianiaceae
>   Taccaceae => Dioscoreaceae
>   Francoaceae => Melianthaceae
>   Didymelaceae => Buxaceae
>   Maundiaceae => Juncaginaceae
>   Rhoipteleaceae => Juglandaceae
> 
> Of course different sources will agree to disagree with regard to these
> and similar lumping/splitting issues, it is just that if you are using
> GRIN as an exemplar of APG III genus placements it is as well to be
> aware where the two systems presently differ. There are also a couple
> of spelling variants (Ripogonaceae => Rhipogonaceae, Toricelliaceae =>
> Torricelliaceae) to be aware of as well, again found differently
> spelled depending on the source you prefer.
> 
> In any case GRIN are to be commended for making all their data
> available so freely for download, to enable such comparisons to be
> undertaken without drama (thanks, GRINners!)
> 
> Regards - Tony
