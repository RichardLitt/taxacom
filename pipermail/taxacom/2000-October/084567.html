Mike,
     Since there are no formal rules in the Code for taxa at this level,
there is no single "correct" spelling.
      One often also sees it spelled Cestodea, which is the way I spell it.
This is because there is a noticeable trend in using an -ea suffix on Class
level taxa, and although Cestoidea also has this ending I think there is
potential confusion since the -oidea ending is the formal ending for
superfamilies.  Likewise, I prefer Class Nematodea, and do not use Nematoda
or Nematoidea.
