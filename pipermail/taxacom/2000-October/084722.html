The Bishop Museum's web server and email address domains have changed
from bishop.hawaii.org to bishopmuseum.org. We have been using the
new bishopmuseum.org along with the old domain for about 2 years now,
but now the old domain name has expired and is no longer in the DNS
database, so using it will get you nowhere.

E.g, our museum's home page has changed from the old
http://www.bishop.hawaii.org to the new http://www.bishopmuseum.org/

Note that all web page url's after the slash remain the same.

All email addresses to the Bishop Museum now take the form of
[username]@bishopmuseum.org

Please change all your web bookmarks and addressbook entries to
indicate these changes.

Apologies for the inconvenience these changes may have had on some of
our web users and email correspondents.

Aloha,

Neal Evenhuis
