I don't recall exactly what Tom Lammers said about nomenclature and
classification being "distinct and should be treated as such," but I don't
think this is right.  Nomenclature and classification are inextricably
linked:  if I discover what I think to be a new taxon, I can only declare
it as new in reference to an existing classification and whatever name I
assign it is also a function of where it fits in a classification.  I
don't see how a functional system of nomenclature can exist without
reference to a classification or vice-versa.
