Martin Wefald's program for converting township/range/section data to
latitude and longitude is now available through anonymous FTP at
cc.usu.edu.  There are three files that need to be copied down.
To get them:
>FTP cc.usu.edu
ftp> login anonymous
enter your id as password:_________
ftp>cd disk$util:[stipoid.convert]
ftp> dir
Directory UTL:[STIPOID:CONVERT]
CONVERT.EXE;1  148
FACTORS.PRN;1  232
HALF.PRN;1      40


Total of 3 files, 420 blocks

ftp> get factors.prn
ftp> get half.prn
ftp> binary   <<<<<<<<very important!!!!!!!>>>>>
ftp> get convert.exe
ftp> quit

An instruction page comes up when one types "convert".  It is a program
pcs.  Martin's address, normal and email, are on the instruction page.
Let me know if there are problems (stipoid at cc.usu.edu).  Even using this editor is not
something I do a lot.
Mary Barkworth
