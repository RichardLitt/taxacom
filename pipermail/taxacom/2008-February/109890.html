Looking at the comments so far and thinking about Chris Lyall' list

The aim is for a set of metadata elements for documenting checklists etc.

Many of the terms mentioned by Chris could be covered by using something 
like the  Dublin Core Metadata Element Set as extended.

http://dublincore.org/documents/dces/

Many years ago a number of us were involved in extending Dublin Core to 
add 4 dimensional geographic elements (to describe any object in space 
and time from normal latitude/longitude, UTM geographies to the position 
of stars in the universe, positions of an organ in the body and from 
eons to nanoseconds).  So by just using part of that one has the 
geography and time covered.

http://www.alexandria.ucsb.edu/public-documents/metadata/dc_coverage.html

Add a few extra Elements to Dublin Core and you may well be there.  Then 
back to the original; message - determining what those Elements should be.

I still think using a one or two question survey on Survey Monkey one 
would get some sort of handle on what people understand by each of the 
categories.

Hope this helps
