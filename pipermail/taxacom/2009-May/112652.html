Dear All,
      The fact that this genus name does not appear in Nomenclator
Zoologicus would indicate to me that this generic name is probably not a
validly published taxon.  It apparently was listed by Systema Naturae
2000 (as unallocated?).    
     The only previous reference I could find in connection with this
generic name seems to be Brusca and Brusca, 1990, in their book
"Invertebrates".  I don't have that book, but perhaps some who does have
access to it could see if it is listed in the index of that book.  I
have read parts of that book in the past, and it doesn't seem to be the
type of book that would be describing and naming new genera (although it
might have mentioned it as an odd genus name due to the unusual length
of the name).  As I said above, I really doubt that it is a validly
published taxon.  
           -------Ken Kinman
