The CalFlora Database at

http://elib.cs.berkeley.edu/calflora/

provides open internet access to a rich and expanding data resource
for the vascular plants of California (over 8k taxa).  The Texas A&M
Bioinformatics Working Group has been exploring various web
manipulations of full text indices derived from downloads of CalFlora
data files.  A new user interface for access to CalFlora indices for
both mapping and text is now open at:

http://www.csdl.tamu.edu/FLORA/calsys/cabase.htm

This system combines programmed HTML production with full text
indexing to produce pre-formatted, user-selectable string queries to
map and text indices using both technical and local names.
Taxon-specific data now include expanded web references to ancillary
information and images.
