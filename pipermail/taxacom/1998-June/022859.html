1998 
The Texas A&M Bioinformatics Working Group has recently updated our
on-line herbarium specimen browser at:

http://www.csdl.tamu.edu/FLORA/tracy/hsb.html

This system, developed in collaboration with the Flora of Texas
Consortium, provides access to label data from 94, 457 Texas
specimens from 7 State herbaria.  Output, either listings or
county-level maps, can be adjusted by the user via selection of
various display options.  Color-coded divesity maps (Texas counties,
either specimen or taxon number) can be generated

Data accessed by this system has been entered using the Tracy input
system

http://www.csdl.tamu.edu/FLORA/input/inputsys.html

which is available for download and installation (Win95).  Base data
files are  also available at:

http://www.csdl.tamu.edu/FLORA/output/outputa.html

An overview of the system ant its development is available at:

http://www.csdl.tamu.edu/~erich/webnet.html
