New URL for the AAU (Aarhus) Database: www.aubot.dk  and follow the link

 

This site provides access to the main AAU herbarium database with
117,753 records of plant collections, mostly from Ecuador, Thailand, and
Western Africa (Senegal, Burkina Faso). The database includes 1378 type
collections.
