(2) EMAIL ADDRESS FOR LVB SUPPORT

Please use the following email address for LVB support:

Daniel Barker <sokal at holyrood.ed.ac.uk>

This is the documented address for LVB support, but I occasionally

(3) ABOUT LVB

LVB is a free phylogeny program, using the simulated annealing
heuristic to seek parsimonious trees. It is mainly intended for large
DNA data matrices.
