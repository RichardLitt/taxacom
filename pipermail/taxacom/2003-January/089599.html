Dear Taxacom member,

Today we have released MorphoCode 1.0. MorphoCode is an application to
code continuous data for cladistic analysis, implementing the gap
weighting method of Thiele (1993). MorphoCode imports continuous data
(e.g. exported from Excel), applies the gap weighting method and
exports the newly coded data to a Nexus file.

A robust and theoretically well-supported method for coding
morphometric data was proposed by Thiele (1993). This method relies on
differential weighting of gaps between coded states within one
character. The downside of this method is that it requires many
calculations. This is the main reason why this method, although
published in 1993, has only been used in a few papers throughout the
taxonomic literature. Most papers keep using other, inferior coding
methods.

MorphoCode is available for free on the MorphoCode webpage:
http://www.kuleuven.ac.be/bio/sys/mc. It is an open-source software
project. Feedback is much appreciated.

MorphoCode requires Mac OS X 10.2 or higher.
