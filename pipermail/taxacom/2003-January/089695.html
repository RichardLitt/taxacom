Hi Anthony,

I've been working on such a system for a number of years now.  You can get a
PDF of a DRAFT(!!) copy of the data model at:

http://www2.bishopmuseum.org/PBS/schema/PyleSchema.pdf

I've been working on a front-end to this in MS Access pretty steadily for
about a year now, and am developing it SPECIFICALLY as a tool to help me
complete a monograph of a family of reef fishes that I'm working on. Every
aspect of it -- from the data model to the user interface features -- is
being designed and developed from the perspective of a taxonomist, trying to
organize relevant taxonomic data.

Note that the DRAFT data model linked to above only deals with the
relationships between Taxon Names, Agents (people & organizations), and
References....but the working program is much broader in scope, dealing with
locality data, specimen/observation/collection object data, etc., etc.

I'm hoping that, by summer, I'll be able to offer up the front-end as
freeware, and will expand the data model description to include all of the
components.  For now, I'm keeping it flexible, and plan to follow
international standards as they are firmed up (e.g., ABCD, etc.).

Aloha,
Rich

actually linked to anything right now.  I plan to fix that at some point
