2022 
 It should be noted that the whole publication date issue is a mess, but, luckily, it doesn't matter most of the time. It only matters if there are competing names for the same taxon, both of which are recently proposed. One of the main pitfalls is that hardly anyone knows to check that a journal has a specified archive on ZooBank. If it doesn't, then preregistration fails and new names fail to be available from e-first versions of record, even though they have been preregistered on ZooBank. One complication here is that many people preregistering publications on ZooBank create a new record for the journal, even though one may already exist with a specified archive. If they don't specify an archive for the new duplicate journal record, then we have a situation where there is no specified archive for the journal record associated with the publication, but Rich Pyle can at any stage merge the duplicate record with the original journal record with a specified archive. I forget what the consquences are of this, in terms of the date of specified archived, but it all gets a bit too complicated!
Stephen
