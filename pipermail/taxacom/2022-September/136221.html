Yes, if the Code requirements are not fulfilled, the names are not available. If the Code requirements are fulfilled with the paper publication, the paper publication will make the names available. Most journals are aware of it. Some are not for whatever reason and cause problems.
We are discussing possible solutions for “limbo names” for the next edition of the Code, which is in preparation, i.e., for names that never fulfilled all requirements of the Code. Some electronic-only journals are ignorant or negligent regarding Code requirements and cause even more problems. Your paper involves a paper version which provides the solution. Yes, there are dating issues, but not following rules of the Code can easily cause problems. That’s why we have the rules in the first place.

Cheers

Frank
