Apologies for cross posting,

GrassBase has been updated! There are now 61,141 names within the
nomenclature database and 11,086 accepted species with accompanying
descriptions. There are also 703 generic descriptions produced using
intkey and the gesumm.bat utility found within the test section of the
DELTA website. Changes within the databases are as follows:
Descriptions

    * New descriptions added
    * External links updated

Nomenclature/Synonymy

    * New names incorporated - this includes updates found in Flora of
China and the Catalogue of New World Grasses, with ongoing work on the
new Flora of North America volume.
    * Geography complete to TDWG Level 3 (Botanical Country)
    * Possible origin of unknown names (Lists>Unknown Names)
    * Lists all names associated with a genus (Lists>Genera>All)

Software

GrassUtils has become DeltaUtils - this now only contains the features
which external users would find useful

CultCode has been updated to the 2004 code for cultivated plants.


Please don't hesitate to contact me should you have any queries or corrections.
