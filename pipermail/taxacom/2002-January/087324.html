I must apologize for my previous message about Australian specimens.  I was
given some incorrect information.

Overseas institutions do NOT need to re-register to receive Australian
specimens if they have an existing and valid CITES number.  It is only
Australian institutions which need to re-register.
So, if you are a non-Australian institution, and you have a CITES number -
then it is business as usual and you do not need to do a thing.
Sorry for the confusion.
