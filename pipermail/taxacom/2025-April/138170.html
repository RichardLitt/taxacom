I want to make sure I understand the code with regards to subsequent 
type species designation in a particular case in ischnoceran chewing 
lice.

Nitzsch (1818: 293) published the genus name Goniodes (as a subgenus), 
but did not designate a type species. The first species he listed under 
Goniodes was "Goniodes falcicornis", a nomen nudum. However, he placed 
the available name Pediculus pavonis Linnaeus, 1758, as a synonym of 
this name.

Johnston & Harrison (1911: 326) designated "G. pavonis L. (syn. G. 
falcicornis N.)" as the type species of Goniodes. This has been 
universally accepted since then, and G. pavonis is the name used to this 
date.

As I understand Article 67.2, the fact that Nitzsch did not cite the 
nominal species using an available name would mean that "G. falcicornis" 
(and thus G. pavonis) are not eligible for designation as type species 
of Goniodes.

Is this correct? Does this mean that G. pavonis is ineligible to be 
chosen as type species of Goniodes, or is the fact that P. pavonis was 
included as a synonym save it?

Grateful for any help!
