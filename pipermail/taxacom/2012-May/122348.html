With col_workbox you can compare a list of species names (csv file), in 
one run, against a compilation (denormalized data) of the Catalogue of 
Life species data.
As return you get a csv file with the compare results. col_workbox is 
distributed as a virtual machine and is designed to run on a local 
computer.
You have to install this virtual machine by using a virtualization 
software such as VirtualBox which is free software and run on
Windows (xp, vista, 7), Linux, Solaris and OS X.
Once the virtual machine is imported into VirtualBox you can start the 
appliance and you can use your preferred
internet browser to connect to col_workbox by the url:
http:127.0.0.1:2222

No further installation is needed.

Detailed instructions are included in the download (795mb) package.
