You will find something quite similar of this graphical display in my website (FLOW database).
You can have a look to :

http://hemiptera-databases.org/flow/?page=explorer&db=flow&lang=en&card=taxon&rank=species&id464
http://hemiptera-databases.org/flow/?page=explorer&db=flow&lang=en&card=taxon&rank=species&id405
http://hemiptera-databases.org/flow/?page=explorer&db=flow&lang=en&card=taxon&rank=species&id13
http://hemiptera-databases.org/flow/?page=explorer&db=flow&lang=en&card=taxon&rank=species&id731

The tool is unfortunately not fully developed (lake of informatics resources to finish it unfortunately ... ) but as soon as there is no circular taxonomical stories (status revisvisco for instance) it runs more or less. You can also have some fun with the parameters... 
Of course the result depends totally from the data present in the database and might provide wrong or incomplete schemas if the data are incomplete (which is always the case with large databases...).
