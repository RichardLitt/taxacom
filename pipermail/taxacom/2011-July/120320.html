You can now see the results of an Index Herbariorum query plotted on a
map - the option now  appears on the Index Herbariorum main search page:

 

http://sciweb.nybg.org/science2/IndexHerbariorum.asp
<http://sciweb.nybg.org/science2/IndexHerbariorum.asp> 

 

Clicking on the pointer for a site results in a balloon with a summary
of information about the herbarium at that site and a link to the full
record.

 

I welcome corrections to the geocoordinates for herbaria. Our goal is to
make the position of the pointer for each herbarium as accurate as
possible. If possible, please submit corrected coordinates for the
entrance to the  building in which the herbarium is housed, preferably
in decimal format, e.g., 45.5131,-122.6861). 

 

Corrections can be entered using the "Send comment or correction to the
Editor of Index Herbariorum" feedback link, which can be found in each
herbarium record.

 

The map search page also has an option for viewing all herbaria of the
world on a map - fun, but not recommended for slow internet connections.
