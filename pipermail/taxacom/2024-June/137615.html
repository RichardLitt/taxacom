 Just to be certain that we are clear on this, note that if family group name A is given precedence over family group name B, B can still be used as the valid name for a subgroup of A which does not include the type genus of A. So, family A-idae can contain two subfamilies, A-inae and B-inae. It is just that B-inae cannot include the type genus of A.
