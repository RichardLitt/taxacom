I think the relevant article of Code is 35.5, which says "If after 1999 a name in use for a family-group taxon (e.g. for a subfamily) is found to be older than a name in prevailing usage for a taxon at higher rank in the same family-group taxon (e.g. for the family within which the older name is the name of a subfamily) the older name is not to displace the younger name."

Best wishes,

In the situation described by Michael (and which he would like to preserve), Pseudocrenilabrinae Fowler 1934 is given precedence over Haplochrominae Hoedeman 1947 at subfamily rank, while Haplochromini Hoedeman 1947 is given precedence over Pseudocrenilabrini Fowler 1934 at tribe rank.

This is, actually, in direct violation of Art. 23.3.1.

I don't think the Code offers a way to preserve this type of situation.

('Haplochromini' should probably be called Pseudocrenilabrini -- this name is senior, and I see nothing that invalidates it.)
