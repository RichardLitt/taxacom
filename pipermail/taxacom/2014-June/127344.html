I would be interested to know from the code buffs on the list what the
zoological code says, if anything, about the commercial sale of type
specimens. I am curious as I came across an eBay example of a paratype
being sold (I suspect it is from a private collection because there were
many paratypes assigned for private collection specimens).

The fact (assuming the claim is true) that the specimen is a paratype seems
to be used as a justification for a high bidding price. It would seem that
there would be a lot of room for fraudulent sales if the type label is
printed rather than handwritten.

John Grehan
