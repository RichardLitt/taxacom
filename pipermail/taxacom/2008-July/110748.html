Hi Roger,

myNature project does this for several years now.
http://mybiosis.info/nature/portal.php?pagename=firstpage

Users are able to contribute, & comment and provide IDs for other 
users observational data (with repository consisting in images). For 
some records we have more than one person contributing to one ID 
(this is a truly collaborative work). Contributions appear live and 
the "editorial process," if necessary (depending on reality of 
record),  is done through community contribution (which include taxon 
specialists and non-specialists).

All the best,
Adorian
