Vicieae has not been allowed since the 1961, Montreal Code.

Both Faboideae or Papilionoideae are allowed, with the same 
meaning, and have been since the 1983, Sydney Code. They 
are not quite interchangeable, as Papilionoideae can only be 
used for a subfamily of the Leguminosae. If the family is named 
Fabaceae then the subfamily must be called Faboideae.
