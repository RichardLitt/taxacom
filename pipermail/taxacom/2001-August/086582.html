Ron Gatrelle wrote:
>If any of us with any Code, use it (or author it) from a
>versus predisposition then I think we are bound to inevitably misuse it to
>suit ourselves rather than science.
>
>Knowing the ego of man, it is his compulsion to change what
>is not broke to simply leave his mark on it - or suit his own agenda. When
>will the Code's future committees come to see their selves not as a
>changers of the Code but maintainers?
>
>Which brings me to my last editorial point.  Over these many decades, a lot
>of minds have worked on, a lot of philosophy been applied to, and a lot of
>wisdom incorporated into the IC_N codes. Each is a harmonious, tried and
>proven set of principles which individually form singular Principle of
>Principles. Knowing only the ICZN, it seems to me it has reached that
>harmony that now only waits for its users to comply.

To all points I can only say, very important. The Bacteriological Code has
been formulated over a good number of years and has been updated at regular
intervals. I find myself in the position of doing quite a lot of the
current revisions. Some revisions are necessary because the original
authors of the Code could not imagine that such things would happen and the
other problem is that some people insist on trying to interpret something
into a wording which was not intended. In the former case one has to make
some additions within the framework of what already exists to "stop the
gap" and in the other case one has to retain the concept but make the
wording explicit. I am fortunate because I can still consult one of the
original authors of the Code written in 1975 which is the basis of the
present Code. Unfortunately one of the great problems in bacteriology is
that far too few people consult that Code and this is why mistakes arise in
the "interpretation", some of which indicates that the printed version may
adorn the desk, but was never opened, or if it was, it was never read with
care. I wonder if botanists and zoologists have similar problems.
Brian
