Dear TAXACOM'RS/DELTA users,

We did develop a program to convert Natural Language Descriptions into DELTA
format. It can handle files containing descriptions of Taxa and build the
CHARS, ITEMS and SPECS files in an interactive way. It can also add items
from N.L.Descriptions to existing DELTA files.

The program was not intended to be a TAXASOFT product in the first place, but
we can serve you, converting (large sets of) descriptions into DELTA format
already at this moment.

If you need more information, please contact me, Eric.
