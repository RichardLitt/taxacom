Dear Tony,

If your logic was right, then the species-group name Daphnia pulex
(Crustacea: Daphniidae) is a homonym of the genus-group name Pulex
(Siphonaptera: Pulicidae), the species-group name Dichotomius bos
(Coleoptera: Curculionidae) is a homonym of the genus-group name Bos
(Mammalia: Bovidae), the species-group name Oncylocotis curculio
(Heteroptera: Enicocephalidae) is a homonym of the genus-group name
Curculio (Coleoptera: Curculionidae) and so on, there are literally
thousands of such. It is very evident that the current practice is *not *this,
no one considers these homonyms and no one replaces a species name if it
turns out that it is formed by the same string of characters than a generic
name or vice versa, and the same goes for any "cross-rank" homonyms. If
your logic was right, no tautonyms (Vulpes vulpes) would be possible, as a
genus-group name and a species-group name could not be identical.

Homonyms are only within a given rank: within the species-group, within the
genus-group, within the family-group. *Within the given group *their rank
does not matter, e.g. Physoderinae Miller, 1954 (a subfamily within
Heteroptera: Reduviidae) is a junior homonym of Physoderina Chaudoir, 1877
(a subtribe within Coleoptera: Carabidae), this is a logical consequence of
the Principle of Coordination (see Glossary). But they do not enter into
homonymy with names in another rank-group.

You are right that Art. 52 does not explicitly specify that homonymy is
only possible within a given rank-group, but the wording of Arts. 55, 56
and 57 implies this quite clearly. ICZN might consider to add a more
explicit remark about this in the chapter on homonymy in the next edition
of the Code.

With best regards,

David Redei

>
> My reading of the relevant portion of the Code ("Article 52. Principle of
> Homonymy: 52.1. Statement of the Principle of Homonymy: When two or more

> name.") is that it does not constrain potential homonymous names to be of
> the same rank, or group i.e. species-group, genus-group, family-group) and
> that therefore the name for the subtribe is invalid. Would this concur with
> the opinions of those more expert than myself?
