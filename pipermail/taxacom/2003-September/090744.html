Hi Mary,

The Unicode code point for the identity symbol is 2261 (hexadecimal) ? 8801
(decimal).

So on a Web page use a numerical character reference of either "&#x2261;" or
"≡".
Also, according to the HTML 4 specifications, "≡" will also work.

Of course this assumes that the viewer of the web page has a browser which
is capable of
displaying the symbol. In this case, I think, that's a reasonable
assumption.
