1993 
                   NEODAT Project Announcement no.11/93

     Documents and data files integrating the NEODAT Geographic
Dictionary and the NEODAT Drainage Dictionary are now available
in the NEODAT ftp server.  These authority files contain a set of
international standards intended for use in fish collection
management systems in museums participating in the Inter-
Institutional Database of Fish Biodiversity in the Neotropics
(The NEODAT Project).  Although primarily intended for use in
neotropical fish collections, these standards may be useful for
other biodiversity applications.

To access the NEODAT FTP Server:
      ftp say.acnatsci.org
      login NEODAT
      get readme.1st

Please send any comments and suggestions to:
          neodat at say.acnatsci.org.
