                                                             16 January 1998

New versions of Intkey, a program for interactive identification and
information retrieval, are now available at the DELTA Home Page:
http://biodiversity.uno.edu/delta. The Windows 95/NT version can access its
data and images over the Internet. It can be installed as a helper
application for Web browsers, so that an identification session can be
started simply by clicking on a link in a Web page. Several data sets using
this capability are available at the above site.
