Apologies for not saying where to find the free graphics program GNUPLOT.
I just asked a computing officer, and within a few days it appeared.

Those lacking such luxury can download GNUPLOT from:

ftp://sunsite.doc.ic.ac.uk/packages/gnuplot/

It works with DOS, Windows, Unix and possibly other systems. Apart from
the documentation, help can be had form the newsgroup
comp.graphics.gnuplot. If you can't find this easily, see the README file
at the site above for how to subscribe.
