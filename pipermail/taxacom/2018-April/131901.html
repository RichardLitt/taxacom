Dear John Grehan,

are you using the quickie.run script to run the analysis? Because in the
script it says:

"        Group supports are calculated by TBR-swapping the trees
        found, keeping note of the number of steps needed to
        loose each group.  The labels on branches show absolute
        and relative bremer supports (Goloboff & Farris 2001).
        *Groups indicated with a question mark (?) are those*
*        for which the absolute bremer supports appear to be*
*        10 or more...* "

This is the only reference I can find. If In understand correct this is how
that script calculates the Bremer support. Try to use the bremer.run script
instead (see attached), after you get all the most parsimonious trees.

You could also ask this question to the Google Group fot TNT at
https://groups.google.com/forum/#!forum/tnt-tree-analysis-using-new-technology

They usually reply very fast!

Hope it helps,
