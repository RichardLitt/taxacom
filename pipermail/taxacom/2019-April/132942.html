I should perhaps add that, in IRMNG at least, it is possible to use year as
a search term within the authority, in addition to other options such as
rank or taxonomic filter, to generate lists on-the-fly via the web version
- in case this is of interest to any readers. For example to get a list of
genus names published in 2010 as currently held, go to the "advanced
search" page http://www.irmng.org/aphia.php?p=search&adv=1 , set authority
"contains" 2010, rank "is" genus and you will (currently) get the list of
all 2,495 names that fit the search criteria (the set will include a few
that might be e.g. published earlier and emended in 2010, but those can be
weeded out). You can also restrict the list to e.g. Mollusca or any other
desired group if you so desire. (You can also save any search as a direct
link if you wish, but the URL is a bit long). This is a type of search I
often wish for in other online systems but do not always get...
