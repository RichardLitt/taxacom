Dear Dr. Dallwitz,

I would like to contribute to the DELTA Project with the Portuguese
VOCABULARY below. Feel free to distribute it with the DELTA package,
if you find this useful.

NOTE: Following a suggestion by Dr. Joe Kirkbride, I have modified some
words in order to include the Portuguese accented letters. The phrase
enclosed in < > tells which character in the extended IBM character is
supposed to be used for each accented letter. The reason for coding that
in this way is that our machine refuses to process e-mail messages
containing extended characters. By the way, I am sending this message to
the entire discussion list, and not for your address only, also because
our machine refuses to send messages to Australia (I don't know why).

*COMMENT  Portuguese Vocabulary
          Supplied by M.J. Cavalcanti (January 1994)

*VOCABULARY
#1. ou
#2. a
#3. e
#4. vari<IBM extended character set, character 160>vel
#5. desconhecido
#6. n<IBM extended character set, character 132>o aplic<IBM extended character
 set, character 160>vel
#7. variante
#8. n<IBM extended character set, character 132>o codificado
#9. nunca
#10. m<IBM extended character set, character 160>nimo
#11. m<IBM extended character set, character 161>ximo
#12. at<IBM extended character set, character 130>
#13. ou mais
#14. .
#15. ,
#16. <alternate comma> ,
#17. ;
#18. <decimal point> ,
