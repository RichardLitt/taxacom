1994 
                  NEODAT Project Announcement no.1/94

     U.S.A. counties have now been added to the NEODAT Geographic
Dictionary.  The NEODAT Geographic Dicitionary is an authority file
containing international standards intended for use in fish collection
management systems in museums participating in the Inter-
Institutional Database of Fish Biodiversity in the Neotropics
(The NEODAT Project).  Although primarily intended for use in
neotropical fish collections, these standards may be useful for
biodiversity projects dealing with the North American fauna and
flora.

     The NEODAT Geographic Dictionary can be obtained from the
NEODAT FTP Server.  Files GEODICT.DOC and GEODICT.TXT contain
an ASCII version of the NEODAT Geographic Hierarchy.  File
GEODIC14.DAT contains geographic coordinates for each county.
The latter is in Btrieve format and can be used by FishMap MUSE Edition
version 1.8.3 or above.

To access the NEODAT FTP Server:
      ftp say.acnatsci.org
      login as: NEODAT
      get readme.1st

Note: The NEODAT FTP Server does not require a password, but you must
have a network address properly registered with your Internet
Domain Name Server.

Please send comments and suggestions to:
          neodat at say.acnatsci.org.
