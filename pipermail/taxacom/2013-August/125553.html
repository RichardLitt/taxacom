Doug,

You can download the entire list as a CSV file using the link at the
bottom. That file can be opened in excel and then you can get counts, etc.
You could even import it into access or filemaker and then do your own
searches/filters for certain taxa etc.

OR you could go to the Arctos search home page and do that directly:

http://arctos.database.museum/uam_ento_all

Cheers,
Derek
