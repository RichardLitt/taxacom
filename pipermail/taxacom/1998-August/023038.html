1998 
An update of the Tracy herbarium data input system (vers. 2.2) is now
available at:

http://www.csdl.tamu.edu/FLORA/input/inputsys.html

See 'most recent updates'.

This Win95-based system, under on-going development by the Texas A&M
Bioinformatics Working Group for the Flora of Texas Project, is
designed for rapid specimen data entry and easy output of files that
are compatible with the Herbarium Specimen Browser at:

http://www.csdl.tamu.edu/FLORA/tracy/hsb.html

which provides web access (listing/mapping) to herbarium specimen
data.  Recent updates of the 'Browser' database, mostly derived from
herbaria using the Tracy input system, have brought the total number
of vascular plant specimens (currently limited to Texas) references
to over 100k.
