You are correct of course but my point is that you should collaborate with
existing project to drive for this service to be made available, assuming
you think taxonomist need this service, rather than start a new project. If
you did the latter (start a new project), where would you obtain data? Would
you obtain permission from existing data custodians who probably hold
copyright in their data compilation? Or would you go back to original
sources and keyboard these data again? Do you have any idea of the size of
the dataset you intend to display in static pages? There are definitely well
over 300,000 generic names across all Kingdoms with over 35,000 for the
letter 'P'! -- 35,000 x 7 = 400,000 lines for the 'P' page ... :o(

I'm not saying this should not be done because it should be, but my
suggestion is that you contact, for example, UBio, with this proposal.

Paul
