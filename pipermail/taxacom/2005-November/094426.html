Dear Vitor,


I have used Goloboff et al's program TNT.  It runs very quickly and

is fairly user friendly.  You constrain nodes by interfacing with

your tree of choice and run an analysis for each constraint.  It is a

little repetitive to run analyses for each constrained node, but far

quicker than with traditional searches.  Those more computer-savvy

than me might know how to run a batch file to compute support for all

nodes with a set of runs.  The program is available with a free

10-time trial for pc users.  Mac users and those that wish to

purchase a password must make arrangements with the authors.




Here is the official TNT page:

http://www.cladistics.com/aboutTNT.html
