Afraid I don't know anything about Carex nomenclature.

As to priority I may direct your attention to Art H.4 of the ICBN.
Nomenclatural status depends on the parent taxa: i.e. everything derived
from a particular parentage gets the same name (the earliest legitimate
name).

As this rule is phrased in the widest possible terms, it does appear that if
one of the parent taxa gets a wider circumscription then all the existing
hybrid names (in that rank) for the parentage in the new circumscription
should be considered, when deciding on priority. So, if C.alsatica is the
first name published, yes it should be adopted.
