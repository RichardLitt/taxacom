One thing which makes it much easier for tools like iSpecies is if
databases have a simple API by which they can be queried. For example,
if

http://www.elaphidion.com?q=Xixuthrus+domingoensis&format=xml

returned an XML document giving details about the images available for
that name, then life would be much simpler. The Yahoo Image Search web
service site
(http://developer.yahoo.net/search/image/V1/imageSearch.html) might
give you some ideas. This, by the way, is why I used Yahoo rather than
Google images -- Yahoo makes it easy to search, Google doesn't (their
main search engine excepted).
