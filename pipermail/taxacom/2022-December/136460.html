On 29-Dec-22 6:22 p.m., Derek Sikes via Taxacom wrote:

> Can we all stop using the term 'species' as a sometimes synonym for 'specific epithet'?
> This is a super widespread problem, made all the more common by all the database search interfaces that have a field called 'species'.

* while I couldn't agree more when this is done in prose, in a 
hierarchical format, such as the database entry form given as an 
example, each of the categories is subordinate to, and part of, the ones 
above it.

A related problem is using the specific epithet in the place of the name 
of a species, and writing "cinereus" when "Plethodon cinereus" is meant 
(a problem I was alerted to fret about by Bill Brown in his evolution 
course at Cornell in 1968).

fred.
