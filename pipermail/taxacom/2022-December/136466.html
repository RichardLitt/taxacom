 "The species name" can mean either the binomen or the specific epithet, provided the the context makes it clear which is meant.Taken out of a specific context, the question "what is the species name of humans?" has two possible answers, but that isn't really problematic. It is like "what does the word "right" mean?" It can mean either the opposite of left or the opposite of wrong, or a "right" that we are entitled to, like "free speech". It should be clear from context which is meant. IMHO, it is a mistake to think that letting context determine meaning is somehow "unscientific".
Stephen
    On Saturday, 31 December 2022 at 05:03:25 am NZDT, Yancey, Thomas E via Taxacom <taxacom at lists.ku.edu> wrote:  
 
 There is another aspect of using singular species name that emerges when doing taxonomic work. In a study I?m completing thare are instances when a proposed species name has little or no value because of inadequate documentation, but the name is used extensively and indiscriminately in literature. Those instances of using the name need to be mentioned in discussion of valid species descriptions and the most effective way is to simply cite the name without indication of genus, using italics to indicate its original proposed status: e.g. subspatulata. Putting the name in quotes is an alternative, but distracting. Citing it as [species of Author A] is less desirable.

In this case the intent is to discuss a name that is a nomen dubium of little value and indeterminate status, not to communicate about a documented species. A prohibition about using singular species names does not fit. There is a need for some flexibility of this matter in taxonomic literature.

T. Yancey

All,

Can we all stop using the term 'species' as a sometimes synonym for
'specific epithet'?

This is a super widespread problem, made all the more common by all the
database search interfaces that have a field called 'species'.

A species name is composed of 2 words. Our species name is not 'sapiens',
it is Homo sapiens.

And yet so often I see things like this -
