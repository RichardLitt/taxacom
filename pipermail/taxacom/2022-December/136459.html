All,

Can we all stop using the term 'species' as a sometimes synonym for
'specific epithet'?

This is a super widespread problem, made all the more common by all the
database search interfaces that have a field called 'species'.

A species name is composed of 2 words. Our species name is not 'sapiens',
it is Homo sapiens.

And yet so often I see things like this -

https://nam10.safelinks.protection.outlook.com/?url=https%3A%2F%2Fwsc.nmbe.ch%2Fsearch&data=05%7C01%7Ctaxacom%40lists.ku.edu%7C97e7f50c356d43981d0408dae9f39359%7C3c176536afe643f5b96636feabbe3c1a%7C0%7C0%7C638079529755076214%7CUnknown%7CTWFpbGZsb3d8eyJWIjoiMC4wLjAwMDAiLCJQIjoiV2luMzIiLCJBTiI6Ik1haWwiLCJXVCI6Mn0%3D%7C3000%7C%7C%7C&sdata=IpBTHHWEfruF%2FKBPd2o09KjuqAjKLNxSJDrja1rlInE%3D&reserved=0

which uses the term 'species' where it should say 'specific epithet'

And also in introductory biology textbooks where they list something like:

Genus - Homo
species - sapiens

Happy New Year!
Derek
