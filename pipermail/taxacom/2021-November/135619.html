>  Hi all,
>
> A common theme which comes up when discussing the taxonomic literature is
> how to keep on top of it all and keep track of recent discoveries in
> particular taxonomic groups (e.g., what are the latest papers on reptiles).
> Some may recall the uBioRSS tool put together by Dave Remsen and Patrick
> Leary that has sadly been defunct for a few years. Inspired by that earlier
> work I’ve made a start on doing something similar, which you can see at
> https://biorss.herokuapp.com
>
> The goal is to have a tool that enables you to browse the latest
> literature, drilling down by taxonomic group and/or country. I’ve only just
> started populating the underlying database so the number of sources is very
> limited. There is a blog post that gives some background to the project
> https://iphylo.blogspot.com/2021/11/revisiting-rss-to-monitor-latests.html
>
> I’d welcome feedback.
>
> I’m curious as to whether the interface is useful or not. Note that you
> can get a feed for any view so instead of relying on my interface you can
> view the feed in any news reader. If you want an RSS feed for spiders in
> China then you can have that.
>
> I’d also welcome suggestions for journals to source articles from. I’m
> adding the obvious suspects (Zootaxa and ZooKeys, Phytotaxa and PhytoKeys)
> but hope to add others. I’m also looking to add feeds from PubMed and
> Google Scholar (e.g., search for “new species”).
