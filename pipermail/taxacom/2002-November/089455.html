> algorithm can, given a set of data, yield a hypothesis of relationships.

> this hypothesis can only be tested in the face of new data.

COMMENT: Yes, new data is helpful, but you can use hidden data to do
immediate testing. You need to use constraint trees to see what data
supports the most immediate contrary arrangements of branches. If the
support is small, you got a reliable phylogeny, if comparatively large, you
don't. The null is that any three closest lineages are sister groups and all
support is equal and random
