Thomas Lammers wrote:
>
> At 08:23 PM 11/10/02 -0700, Robin Leech wrote:
>
> >If citing web pages, then give the location, day and time of day for the
> >citing, as web pages change fairly often.
>
> I often see this done, but have often wondered if it's to any avail.  Is it
> really possible to retrieve the appearance of a given page at a given
> time?  Can I write to a webmaster and ask to see what such-and-such an
> address looked like the evening of 26 July 1996???

Good point. A better approach for journals and editors would be to require
the file of the webpage and a printed version to be deposited with the
journal, to be made available on request. Some journals have web pages
where accessory material can be made available - that would be one way of
doing it (with the proviso that there would probably be copyright issues
that need to be dealt with).
