BioLink (previously discussed here under taxonomic databases) has a mapping function that allows plotting of data points, lines, and rectangles.  The geographic base maps are ESRI shape files, as used in ArcView, and you can use multiple map layers, such as vegetation type and precipitation, if you can find them in the suitable format for your area.
It requires the commitment to learn the basics of a full-featured database system, but in terms of the functions provided, that should not be too burdensome.
