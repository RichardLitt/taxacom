For Literature Cited, read References.
If an article is cited in the References, then it is understood to be
cited in the text, and vice versa.

If a consultant's report is readily available (e.g., in a government
library,
university library, etc.) for all, then it can be cited in the normal course
of the alphabetical order of the citations in References.  I do not think
that the veracity of the included information should be challenged
simply because it is in a consultant's report.   As we all know, there
are many faulty publications in refereed journals.

If citing web pages, then give the location, day and time of day for the
citing, as web pages change fairly often.

Might be a good idea to make a printed copy of the web page to be
able to hand out to someone in the event of a challenge (then a FAX
or mailing of a copy can be made).

Robin Leech
