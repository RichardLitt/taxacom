This is what I received when I subscribed to Taxacom.  Unsubscribing is just
like subscribing--same address, same command, except the letters "un" in
front of it.

address the message to:
        listserv at usobi.org

the message should say only:
        unsubscribe taxacom

You can also change your options while subscribed.  Then the message should
say only:
        set taxacom XXXX

where XXX is as follows:

to suspend mail service while you are away, SET TAXACOM NOMAIL
[N.B.  This is *the* polite thing to do.  If you don't suspend mail, then
every person who writes to the list while you're away will receive your "I'm
away and will be back xxxxx" every time they contribute to the list's
discussion.]

to begin receiving mail again on your return, SET TAXACOM MAIL

to get copies of your own messages to the list, SET TAXACOM REPRO
to not have the clutter of your own words, SET TAXACOM NOREPRO

to receive an acknowledgement every time the listserv has gotten a message
from you for distributing, SET TAXACOM ACK
to not receive such an acknowledgement, SET TAXACOM NOACK
