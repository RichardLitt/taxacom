Now available:

http://www.iapt-taxon.org/historic/

This offers the various editions of the Code governing 
the scientific nomenclature of algae, fungi, and plants, 
in (approximately facsimile) HTML form,with changes
to the prior edition marked, hyperlinked horizontally 
and vertically (basic principle is that the first letter of 
the actual provision takes the reader forward, to the 
newer edition, while what comes before this first letter 
takes the reader backwards to the earlier edition).

Proposals-to-amend-the-Code have been included,
and integrated, back to the 1981 Sydney Congress
(inclusive).

Please report any errors to me.
