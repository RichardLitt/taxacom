I see several arguments to keep the gender agreement:

1) It will exist in the botanical code and I hate to see that things work differently in both codes as it complicates working with names across codes

2) It becomes hard to remember a name when the genus contains epithets of various genders which David has pointed out. It would also not be possible to built rules in software but instead requires a complete ZooBank or alike lookup. Stephens idea of doing away with a single correct name would be a better option, but might cause other problems.

3) Names with wrong gender agreement are rather painful to read when you do know latin. I am surprised no one has mentioned this argument so far. If you were to write a scientific paper in French and ignored gender agreement reviewers wouldn't be happy. 


What on the other hand if there would be a website to simplify the burden of figuring out the correct gender instead?
Listing the gender of all genera should be an achievable task. One could probably even programmatically generate content by looking at the epithets of the existing names and how they changed between genera. A simple website that allows anyone to check a name according to what is known already, contribute to the genera and epithets and in unknown cases maybe even broker to people who enjoy such research?

Markus

> I will again suggest that what is needed is a move away from the idea of a single correct name for a taxon. Bombus ruderatus is the same name (from the point of view of homonymy) but just a different spelling from B. ruderatum and B. ruderata. If we are to track information on the species, we need to search for all three spelling variants, in case someone has used them. In the same way, we need to search for all synonyms and alternative combinations for the same species. You can call one of the gender variants the "correct" one, but what does that actually achieve? People will still use the other variants, as lepidopterists have been doing all along, without problems. The easiest solution is just to consider all gender variants to be synonyms and you track a taxon by the set of all its synonyms.

> In my opinion, "prevailing usage" is the most swampy and controversial term in the current Code. Glossary defines it as "*that usage of the name which is adopted by at least a substantial majority of the most recent authors concerned with the relevant taxon, irrespective of how long ago their work was published.*" What is "substantial majority"? If there are 100 authors,
> 51 of them uses one usage, 49 the other, it is definitely not a "substantial majority". How about 55 : 45? 60 : 40? 70 : 30? Where is the limit? What if there are only 10 people using the name, and the ratio is 9
> : 1, is it a substantial majority? Can we call 9 people a "majority"? How about a scenario when only 6 people used the name in the past 100 years and their ratio is 4 : 2, is it substantial majority?  What if the ratio is 30:70, but most of the 70 authors publish in exotic journals in exotic languages therefore most of the scientific committee do not read them, while the 30 authors publish in easily available periodicals in universally understood languages therefore all members of the scientific community read them, would we call the 70 as "prevailing usage" in this case?
> 
> This term is a nightmare, lacking any clear definition, you need to rely on your subjective feelings. Moreover, using the "prevailing usage" is highly difficult in practice, since you need to make a major literature search to establish the prevailing usage.
> 
> In my opinion, gender agreement might be surely a trouble for some people who do not want to waste time for learning something supposedly "useless"
> (?), but abandoning it would be a very significant step backwards, highly destabilizing nomenclature. Please note that *the "prevailing usage" is precisely the gender agreement itself: changing the ending of the specific epithets is a practice that has been in prevailing usage in the past 250
> years*.* Our currently existing "prevailing usage" of names is based on gender agreement*, which was overwhelmingly correctly (and yes, sometimes
> incorrectly) applied in all names (minus Lepidoptera).  If you really seek stability, you cannot abandon it.

>>> There is a relatively simple solution to the gender agreement issue 
>>> that I would like to propose.
>>> 
>>> I do not think that lepidopterists really want to impose original 
>>> spellings for all zoological names in other taxa. We have already 
>>> been using original spellings for most species names for a long time 
>>> with exceptions for incorrect subsequent spellings that are in 
>>> prevailing usage (e.g. Papilio pitmanii -the original spelling - was 
>>> changed to pitmani over 100 years ago, and that spelling is in 
>>> prevailing usage so is regarded as the 'correct' spelling under article 33.3.1).
>>> 
>>> I propose that when a species is transferred to another genus gender 
>>> agreement should no longer be applied, and instead use the current 
>>> spelling of the species name regardless of the gender of the new genus.
>>> That way species names would be fixed permanently, so that e.g. the 
>>> species known as Bombus lapidarius, Camponotus herculeanus, and 
>>> Polistes gallicus would continue to be called lapidarius, 
>>> herculeanus, and gallicus even if they were moved to different genera.
>>> 
>>> This suggested 'compromise' could easily be incorporated in the 5th 
>>> edition of the Code by applying the prevailing usage concept, which 
>>> is already widely used in the current Code, with relevant new 
>>> articles to govern these changes. This would actually simplify the 
>>> Code a lot, as many more articles pertaining to gender agreement 
>>> would be removed than the new ones added to implement the system.
>>> 
>>> Previously described species names would continue to use the 
>>> spelling in current prevailing use, even if it is not the spelling 
>>> in the original description, and newly described species group names 
>>> would never subsequently change their spellings.
>>> 
>>> There will be some cases where more than one spelling is currently 
>>> used in the literature, in which case priority could be given to the 
>>> original spelling if prevailing usage is unclear.
>>> 
>>> Some taxonomists will not like my suggested solution, but it would 
>>> solve the whole problem without names having to change from their 
>>> current spellings. I vote for the principle of nomenclatural 
>>> stability which the current Code aspires to. There is nothing more 
>>> stable than species names which never change when they are moved to 
>>> a different genus. I suspect that implementing this suggestion would 
>>> also make life a lot easier for the database people too.
>>> 
>>> Adam.
