 In my experience, a significant number of taxonomists just don't care about small nomenclatural technicalities, like gender agreement and probably aren't even going to take any notice of explicit lists of genders provided to them. I therefore suggest that systems accommodate the actual practice by taxonomists as it is in reality, rather than what someone or other thinks it should be. For gender agreement, systems just need to recognise that different gender forms will often be used for the same name, by different taxonomists. Systems just need to automatically recognise all different gender forms of a name as synonyms. Everyone can then use whatever gender form they consider to be appropriate, which they will do anyway, but the important thing is for databses and the like to recognise the synonymy of different gender forms. It is really not much different to different taxonomists at the same time, or the same taxonomist over time, using different combinations for the same species. These different combinations are also homotypic synonyms that we need to track. We also need to move away from the unrealistic idea of there being a single correct combination for a given species.
Stephen

 I think such an article would be very valuable -- both in terms of properly framing the issue in the context of future editions of all Codes; but also so that whenever this issue comes up again in the future on Taxacom (or wherever), a simple link could be provided to the (open access!) publication.

> > >> We (the ICZN) leave the rules in place, but provide two things that
> > >> would *completely eliminate the need for anyone to learn or
> > >> understand Latin or Greek*:
> > >>
> > >> (1) We provide a single official list of all genus names and their
> > >> genders. Contrary to what others here have claimed, we do *already*

> > >> (2) We provide a single official list that explains which species

> > >> Anything not on the list is treated as a noun, and never changes
> > >> spelling. This is a little trickier to organize, but should also be
> > >> attainable. For example, I've personally screened over 200,000
> > >> species-group names, which is over 10% of all zoological names -
> > >> and other researchers have done the same for their groups.

> > >> taxonomists to learn Latin or Greek, not because gender agreement

> > >> does not need to know Latin or Greek to *look a name up in a list*.
> > >>
> > >> Would you support the implementation of such a system?
> > >>
> > >> Remember, we are aware that people don't like the status quo, and
> > >> we are also aware that completely reverting to original spellings
