Dear All,
obviously the names problem is a central impediment not only for Google: by
which name can you "google" all  information pertaining to one given species?

Did you notice that Google already has something like a "names server"?
E.g., when you go to the English google.com and search for "Carabus
arcensis", they  will return "Did you mean Carabus arvensis ?".
Well, the latter name is used by many beetle enthusiasts .... BUT: it's not
the Code compliant spelling....

So why not be innovative in this direction:
Google's "Did you mean" service gets information on valid and Code-compliant
names approved by, e.g.,  ICZN's envisioned ZooBank and in return Google pays
a piece of a Cent for each search click on taxonomic names...
Not a nice dream?
