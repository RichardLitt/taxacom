I'd like to ask your opinion about a feature that a.f.a.i.k. has not been
implemented in any taxonomic website so far.
A focus-entry in www.peperomia.net gives a small introduction to the issue of
'herbarium names' and gives access to the TRGP (Taxonomic Repertory of the Genus
Peperomia) were manuscript scans of these herbarium names are made available
online.
Please note that manuscript access is offered:
- in a clear taxonomic context presenting legitimate alternative names,
- to give first hand information about the original concept of the herbarium
name author.
- solely concerning names effectively deposited in herbaria as sp.nov / type
(not names just  figuring in manuscripts).
- clear recommendation is provided not to use herbarium names but their
legitimate alternatives.
All this with the only intention to resolve an important name-chaos issue and to
get rid at last of all herbarium names which represent 1200 names or 40% of the
number of effectively published names in Peperomia.
