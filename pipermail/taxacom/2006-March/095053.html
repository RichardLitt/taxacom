Another web-based venue for generating keys is at
www.discoverlife.org.  Follow the link to IDNatureGuides in the left
column to view existing keys.  Contact the operators if you are
interested in creating a key of your own.

I have used both DiscoverLife and Lucid.  Like some of the other key
software discussed here, DiscoverLife lacks some useful functions
like "best feature", and for this reason Lucid is more powerful, but
it's free for both key writer and key user, and will be adequate for
many uses.
