At 08:09 AM 11/12/2009, Karolina Fucikova wrote:
>> this is a botanical code question and I hope someone can help me out.
>> Here goes:
>> In 1888, author X divided the genus Trochiscia into several sections.
>> The name of one section, Dictyococcus, was never used since, as far
>> as I know. Likely unaware of all that, in 1907, author Y erected a 
>> completely unrelated genus Dictyococcus that is still used and
>> recognized as valid. Now, does the earlier name have any priority 
>> over the later one if it isn't the same rank?

Van: taxacom-bounces at mailman.nhm.ku.edu namens Thomas G. Lammers
Verzonden: do 12-11-2009 15:34

> Priority only operates within a rank.  The existence of 
> Trochiscia sect. Dictyococcus X, 1888 has no impact on the genus
> Dictyococcus Y, 1907.

***
Yes, see Art. 11.2:

"11.2.  In no case does a name have priority outside the rank 
in which it is published (but see Art. 53.4)."
