Open review does not have to be "totally" public. If one registers to 
view the manuscript, the entire database containing the manuscripts 
and names can be password protected from unauthorized "viewers" such 
as hackers -- and web bots can easily be kept out with coding so that 
those "phantom" names will not appear in results from web-based 
search queries.
