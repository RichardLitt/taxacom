Dear Gurcharan Singh,

If I am not mistaken, when n = the number of taxa, the formula is
(2(n+1)-5) times the number of trees for n-1 taxa. So for 2 taxa there
is only one tree, for 3 taxa there are (2.4-5).1 = 3 trees, for 4 taxa
(2.5-5).3 = 15 trees and so on. Please bear in mind that this only goes
true for rooted, fully dichotomously branched trees. If the trees are
unrooted, the number of possible trees is one step lower, i.e. 1 tree
for tree taxa, 3 trees for 4 taxa and so on. If polychotomous branching
is also allowed, the calculation becomes more complicated and is beyond
me. But I know there are 26 rooted polychotomous trees for 4 taxa and
236 for 5 taxa. There is something on this in "Cladistics" by Kitching
et al. (1998) Oxford University Press, page 39 etc.

Best regards,
Jan
