I'd like to point out that the number of possible trees for a particular
number of taxa is a mathematical problem, not a taxonomic one. A tree with
any claim to "real" existence is actually a particular nested data set, one
that convinces someone that there is enough relative support for a
particular set of shared advanced character states to imply shared ancestry
rather than convergence. These "real" trees I suppose are common for
relationships that are already intuitively self-evident, but for problematic
groups or Bold Conjectures, they are few and far between.

Given that a data set of random numbers will almost always generate a fully
resolved tree through max parsimony, telling a "real" tree from one
generated by convergence is a problem. There may not be one "real" tree for
any particular set of taxa if the data is insufficient to treat such a tree
as reliable enough to act on (generate a theory on which further work can be
based).

Thus, the number of trees "possible" for a given number of taxa may be zero
if the data are indistinguishable from random at some level of confidence
(some level of reliability at which you can do good science).
