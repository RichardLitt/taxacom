See my post from yesterday on this topic about numbers. A second problem is
that botany, bacteriology and zoology all use slightly different terms for
the concept of "valid".
zoology = valid
botany = correct
bacteriology = correct

This would imply some taxonomic interpretation. Publication according to
the appropriate Code would provide us with a list of:
zoology = available names
botany = validly published
bacteriology = validly published names (which are officially indexed)


I assume that ING (botany) is primarily a list of validly published names.
The botanical NCU lists would, in principle be list of correct names (?),
but I understand that this concept has been dropped. The list from the
Zoological Record would primarily be a list of available names. In
bacteriology we currently only produce a list of validly published names.
In order to gain access to information on whether a name is "correct/valid"
I assume that you will need to consult an expert in the various fields. I
have also seen publications in which the zoological concept of "valid" is
confused with the bacteriological concept of "validly published" - beware
they are not equivalent!

Does this help?
Brian
