I get so annoyed by this "debate". Anyone who understands zoological nomenclature should understand that "published according to the Code" (and therefore publication dates according the Code) is different to "published" in the everyday sense. Therefore if the Code stipulates that a work was published in 1758, then it was published in 1758 (according to the Code). There is no problem here.

Stephen
