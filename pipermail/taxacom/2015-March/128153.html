To answer the question B, other available free software are :
- Xper3 (collaborative editor and identification keys) 
http://www.xper3.fr/?language=en
- Ikey+ to compute single access keys http://www.identificationkey.fr/
- Xper2 ( editor and identification keys, software available on Windows, 
MacOS or Linux) http://www.infosyslab.fr/lis/?q=en/resources/software/xper2
