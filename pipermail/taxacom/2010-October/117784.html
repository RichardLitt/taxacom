There is no question that machine translation can not replace human
yet, so Google Translate may be just a starting point. Apparently
Google used mostly classical text for Latin. If you want to improve
quality of translation one of the solutions might be to use shared
translation memory:
http://translate.google.com/toolkit/
Word usage and sentence structure in botanical diagnoses is rather
standard, so the system will learn pretty quickly.

Cheers,

Vlad
