1996 
The New York Botanical Garden is in the process of cataloging its
approximately 150,000 type specimens.  We intend to make these
records available family by family, as cataloging is completed.
Currently, the following vascular plant families are available
through Gopher:

     Araucariaceae     (  12 records)
     Austrobaileyaceae (   3 records)
     Caesalpiniaceae   (1321 records)
     Calycanthaceae    (   4 records)
     Connaraceae       ( 123 records)
     Cupressaceae      (  45 records)
     Cyacadaceae       (  98 records)
     Dichapetalaceae   (  48 records)
     Ephedraceae       (  13 records)
     Ericaceae         (1214 records)
     Fabaceae          (4208 records)
     Gnetaceae         (   6 records)
     Illiciaceae       (  17 records)
     Lamiaceae         ( 638 records)
     Lardizabilaceae   (   8 records)
     Lecythidaceae     ( 193 records)
     Mimosaceae        (1962 records)
     Orchidaceae       ( 973 records)
     Paeoniaceae       (   2 records)
     Pinaceae          (  85 records)
     Podocarpaceae     (  61 records)
     Taxaceae          (   4 records)
     Vochysiaceae      ( 153 records)
     Winteraceae       (  10 records)


     Basic information from all types in these families has been
captured in the database, but some of the records are more
complete than others.
     Searches can be made on any word in the file.  However, no
more than 1,500 records will be returned for any search, so
searches should be constructed so as not to exceed the limit of
1500 records.

     If any errors are found in the type catalog, please send
corrections to Tony Kirchgessner (tkirchgessner at nybg.org).
