The URL of the DELTA home page is
    http://muse.bio.cornell.edu/delta/
The last `/' was omitted in the original announcement.

Also, some Web browsers (e.g. Mosaic 2.0 alpha 2 for MS-Windows, which is not
the latest version) calculate some URL's incorrectly (because they do not
handle the HTML <base> element). For example, the URL for the index to the
angiosperm-families descriptions is calculated as
    http://muse.bio.cornell.edu/delta/www/angio/extra/index.htm
instead of
    http://muse.bio.cornell.edu/delta/angio/extra/index.htm
As a workaround, you can enter the correct URL directly. Netscape 1.1 beta for
MS-Windows and Mosaic 2.4 for X-Window handle this correctly.
