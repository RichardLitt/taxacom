>> Hi John,
>>
>> I know that for some ORCID seems like yet another bureaucratic hassle,
>> but it’s actually quite useful. Once you have one, any papers or datasets
>> that you publish will be “automagically” linked to your ORCID profile
>> (providing you use the ORCID when you submit the paper or data). You can
>> also add previous publications to your profile, so you get a continuously
>> updated online CV.
>>
>> Perhaps the coolest use that’s relevant to our community is David
>> Shorthouse’s Bloodhound project. He is trying to discover which specimens
>> in GBIF can be linked to specific people, and to do this it helps to have a
>> unique identifier for each person. This is where ORCID comes in. You can
>> use ORCID to uniquely identify yourself, then claim the specimens you have
>> collected or identified.
>>
>> For example, I’m guessing that these specimens
>> https://bloodhound-tracker.net/agent/2493732 and these
>> https://bloodhound-tracker.net/agent/39241 will include material you’ve
>> collected? You can claim these, for a nice example see Torsten Dikow’s
>> profile https://bloodhound-tracker.net/0000-0003-4816-2909 (the
>> "0000-0003-4816-2909” bit in the URL is his ORCID id).
>>
>> For more details see https://bloodhound-tracker.net/about
>>
>> Regards,
