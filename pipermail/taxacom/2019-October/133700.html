>> HAPLOGONOPHORA name. Nov.
>> (Melagonozonia, pro p., Brolemann, 1916.)
>> Since our publication in 1916 (Bull Soc Entom, France, year 1916, No. 1,
>> p.53), we have come to the conviction that it is impossible to maintain,
>> side by side, in the same Order, the Spiroboloid and luloid. We thus
>> institute for the first a new section, the order of the Haplogonophora,
>> which until now contains only the suborder Spiroboloidea.
>> To unify our nomenclature, we modify the names of Meta-gonozonia and
>> Progonozonia, created in 1916, and replace them with:
>> Metagonophora, which only includes forms of the type of our European
>> luloids and perhaps Cambalidae, and
>> Progonophora, encompassing Spirostreptoidea and neighboring suborders, as

>> We will have the opportunity to return later to these great divisions of
