1995 
Dear Computer Taxonomists,

This is to announce the forthcoming release of the first Windows version
of my DIANA software shell, first released last year as a DOS application.
The Windows version has the same general look-and-feeling of the DOS version,
but does not have the ridiculous memory restrictions imposed by DOS, that
caused the DOS version hang the computer rather frequently.

The DIANA for Windows package will also include a newer version of my DELTA
Library of routines for reading DELTA-format files, now placed on a Windows-
compatible DLL that can be called from within Pascal, C or Visual BASIC
(importing libraries for Turbo Pascal and Visual BASIC are provided).

I look forward to hearing from all interested users. Please, send replies
directly to my e-mail account (ORTPRO at vm.lncc.br), and not to the TAXACOM
list, since my mailbox is now emptied on a daily basis and I cannot keep track
of all messages I received from TAXACOM.

All the best,
