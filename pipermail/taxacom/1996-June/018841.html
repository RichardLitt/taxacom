Re:  Bob Poole's query concerning use of Raphidioptera versus the original
spelling Rhaphidioptera:

     I concur with Brothers, Raphidioptera would be the best name choice
here if it is in widest current use.  The Code doesn't apply here, but even
if it did and this were a family-group name, it would be corrected to
Raphidioptera to reflect the original spelling of the generic name
(Raphidia) it is based on, not the original spelling of the group name.
Thus, there seems to be little reason to retain the spelling Rhaphidioptera.
