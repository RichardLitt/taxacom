On 11/30/22 3:54 PM, David Campbell via Taxacom wrote:
> The reference to Galea in Smith on p. xii has a description, so the genus
> seems to be convincingly validated there.

So, the question now is what effect, if any, this has on the use of 
Meyen's name. The mammal name certainly seems to be well-entrenched 
(e.g., https://nam10.safelinks.protection.outlook.com/?url=https%3A%2F%2Fen.wikipedia.org%2Fwiki%2FGalea_&amp;data=05%7C01%7Ctaxacom%40lists.ku.edu%7C25f4c04275464c2f95c108dad330c9f8%7C3c176536afe643f5b96636feabbe3c1a%7C0%7C0%7C638054504616579667%7CUnknown%7CTWFpbGZsb3d8eyJWIjoiMC4wLjAwMDAiLCJQIjoiV2luMzIiLCJBTiI6Ik1haWwiLCJXVCI6Mn0%3D%7C3000%7C%7C%7C&amp;sdata=QYnq%2Fo4Jeh1qPm9c%2Frt54J7QWHpa%2BBVNZHfojgBIDSc%3D&amp;reserved=0(genus)), and it appears 
unlikely that Smith's senior homonym was ever used as valid after 1899, 
so it would appear to qualify as a nomen protectum under Article 23.9 - 
but 23.9.2 does require that someone, somewhere, *needs to publish an 
explicit statement that it IS a nomen protectum*, otherwise Meyen's name 
is still technically unavailable, and someone could potentially come 
along, resurrect Smith's name as valid, and screw everything up. The 
existence of an unnecessary replacement name has no effect except to 
confuse people, unless it's in prevailing usage.
