Agassiz  in the universal index preface says something about "the need to
reform the nomenclature zoologiae".  And mentions nomenclature cleansing.
Well what a busybody. I'm wondering if these parenthetical alternates
qualify as emendations in the current zoo code sense since he doesn't
actually use them himself at all as main items. They're suggestions for
future usages aren't they?

In the main listings the names are as the original authors had them,
together with Agassiz's idea of the derivation - which must be a guess
often - but worth looking at.
