 I am 100% against the renaming of taxa for "cancel culture" reasons. However, at the end of the day, anybody can use whatever name that they like for a taxon and it doesn't really matter, provided that we keep track of all the names that apply to that taxon. So, in a way, "cancel culture" in taxonomy is self-defeating: Sure, you can suppress the validity of a name that is deemed somehow "inappropriate", but you still have to keep the name going in the literature as a synonym, so as to keep track of previous published data about the taxon. At this point I laugh and ask, how does relegation to synonymy really "cancel" anything? If there was a trumpi, for example, it is here to stay. whether as valid or as a synonym. This also raises the point that inappropriateness is subjective. Republicans will continue to use trumpi as valid, while democrats will relegate it into synonymy! Herein lies the road to taxonomic instability, but, as I said, it doesn't really matter. The main thing is simply to keep track of all names for a given taxon, regardless of which one is treated as valid or preferred. A whole lot of fuss about nothing!
