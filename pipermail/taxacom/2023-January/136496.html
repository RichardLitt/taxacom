So far as I understand, if the taxon was called "ab." (aberratio) in the OD,?it is
deemed infrasubspecific under 45.6.2, and is therefore excluded from the scope of
the Code under 1.3.4 -- thus it does not compete for priority.
Such a name will take precedence from the first work (if any) which used it as the
name of a subspecies while simultaneously meeting the other requirements to make
it available.

Cheers, Laurent -
