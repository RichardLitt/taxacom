As far as I can see the 2013 was made availabe, the other name is a 
junior homonym.

The ICZN Code has Appendix A, this is called Code of Ethics, and there 
provision 3 states:

"3. A zoologist should not publish a new replacement name (a nomen 
novum) or other substitute name for a junior homonym when the author of 
the latter is alive; that author should be informed of the homonymy and 
be allowed a reasonable time (at least a year) in which to establish a 
substitute name. "

It would be extremely useful if the Nomenclatur Zoologicus files could 
once again be converted into a useful servoice where all genus-group 
names could be consulted.
