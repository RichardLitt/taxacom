> It would be extremely useful if the Nomenclator Zoologicus files could
> once again be converted into a useful service where all genus-group
> names could be consulted.

Well, the service is "continued" by ION (https://nam10.safelinks.protection.outlook.com/?url=http%3A%2F%2Fwww.organismnames.com%2F&data=05%7C01%7Ctaxacom%40lists.ku.edu%7C1044902a48814452354c08daf1ab7306%7C3c176536afe643f5b96636feabbe3c1a%7C0%7C0%7C638088015933887099%7CUnknown%7CTWFpbGZsb3d8eyJWIjoiMC4wLjAwMDAiLCJQIjoiV2luMzIiLCJBTiI6Ik1haWwiLCJXVCI6Mn0%3D%7C3000%7C%7C%7C&sdata=dCKH9nAQysQEJzzX89exQiXT9qGl27z8PccHbVUgJuY%3D&reserved=0),
although they collect literare (mis-)spellings as well as those originally
published, which can be a source of confusion; also do not comment on the
taxonomic status of names.

Rod has also collected the ION (and earlier, the Nomenclator Zoologicus
data (=Neave) ex uBio) data into his own "Bionames" compilation (zoology
only I believe), see https://nam10.safelinks.protection.outlook.com/?url=https%3A%2F%2Fbionames.org%2Fsearch%2FPlanuncus&data=05%7C01%7Ctaxacom%40lists.ku.edu%7C1044902a48814452354c08daf1ab7306%7C3c176536afe643f5b96636feabbe3c1a%7C0%7C0%7C638088015933887099%7CUnknown%7CTWFpbGZsb3d8eyJWIjoiMC4wLjAwMDAiLCJQIjoiV2luMzIiLCJBTiI6Ik1haWwiLCJXVCI6Mn0%3D%7C3000%7C%7C%7C&sdata=IoGz9m%2B3G%2BO%2F%2Brhy9SJ07FSNJaJbLcwe%2FktqkHO9DUI%3D&reserved=0 ... I am not
sure whether BioNames uses other sources than Neave + ION to create the
BioNames list, also when it was last updated, but I am sure he can comment
further...

My own "IRMNG" also uses Nomenclator Zoologicus data (ex uBio) to 2004,
then ION data (genera only, kindly provided by Rod) through 2014 only, so
more recent names will not be there. For IRMNG (not sure about BioNames) I
try to only include names "published as new", not all the other literature
occurrences also cited in ION. The equivalent search in IRMNG is of the form
https://nam10.safelinks.protection.outlook.com/?url=https%3A%2F%2Fwww.irmng.org%2Faphia.php%3Fp%3Dtaxlist%26searchpar%3D0%26tComp%3Dis%26tName%3DPlanuncus%26genera_only%3Don&data=05%7C01%7Ctaxacom%40lists.ku.edu%7C1044902a48814452354c08daf1ab7306%7C3c176536afe643f5b96636feabbe3c1a%7C0%7C0%7C638088015933887099%7CUnknown%7CTWFpbGZsb3d8eyJWIjoiMC4wLjAwMDAiLCJQIjoiV2luMzIiLCJBTiI6Ik1haWwiLCJXVCI6Mn0%3D%7C3000%7C%7C%7C&sdata=CoynQ%2Fd7bfj6oshsOaQJdgQ92taPIEt0PbSz%2F6m72Qg%3D&reserved=0

If I encounter errors in the uncorrected OCR text that uBio produced, I
correct them in IRMNG, as I find them. Of course the original printed text
(Neave) has errors as well, which I also note and correct as encountered...

Just in case folk are unaware of these efforts. So far as I know, BioNames
will continue being updated, while IRMNG has reached a point where I have
probably done all or most of what my time allows (retired now, since 2014
at least) so may rely on others to carry forward to the future if they so
desire...
