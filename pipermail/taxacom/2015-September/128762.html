I had a number of herbarium databases bookmarked already which are listed
below.. Not only S American Bromeliaceae collections, but plants
worldwide. I have checked all URLs. If there are more available, I would
like to learn about those too. For my purposes (biogeographic research)
zoological databases are also of interest. If anyone knows of websites
