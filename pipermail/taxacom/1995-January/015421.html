I disagree with your suggestion of changing the default by which replies to
posted queries only go to the person asking the question. As I understand
it the listserver protocol is for enquiries to be posted; those with
something worth contributing reply to the person posting the query; if the
material is of general import, he/she then prepares a summary for posting
to the entire list.

To have all replies default to everyone would surely clutter the list. The
request for information about the Convolvulaceae genus (Polymeria) above
need only go to the person needing the information, for example.

As this is of general import, I will try to copy to the list, though it is
not my usual practice.

John
