To enable you to have a single database but not renumber any of your phyla,
you could add a phylum field to the unified database and then use phylum +
catalog number as the unique key for each record.  You'd probably want to use
short coded abbreviations for the phyla, but I imagine someone's already
worked up such a system (maybe SI Invertebrates?).
        Of course, you'll still have to reconcile the differently "evolved"
database structures of the 30+ source files, but that's a separate issue!
        Good luck!
