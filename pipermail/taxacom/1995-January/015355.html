1995 
This message is to announce an upgrade of and new downloading instructions for
Synapo (now version 1.11). There were some problems with downloading reported
so both PC and Mac versions are now available as self extracting archives.

A slight change has been made from the previous version (1.1) which refused to
read PAUP format files if the Begin Data; statement was in the first ten lines
of the file.

The program is available by anonymous ftp from ftp.uws.edu.au
Use anonymous as name and your email address as the password.

P C   V E R S I O N

Located at pub/pc/misc
A single file called synap111.exe - this is an executable self extracting
archive of 3 files:
SYNAPO.EXE - version 1.11 of the program itself
SYNAPO.TXT - information about the program
THOMAS1    - a sample input file in PAUP interleave format
Download synap111.exe in binary mode and run it (type synap111 at the DOS
prompt). The 3 files will be created.

M A C   V E R S I O N

Located at pub/mac
A single file called Synapo111.sea.hqx - a BinHex4 version of a self extracting
archive (Synapo111.sea) of a folder (SynapoFolder) containing 3 files:
Synapo 1.11 - version 1.11 of the program itself
Synapo.txt  - information about the program
THOMAS1     - a sample input file in PAUP interleave format
Download Synapo111.sea.hqx in ascii mode - ftp utilities like Fetch will
usually set the mode and de-BinHex4 automatically which will result in the self
extracting archive (Synapo111.sea) being saved to disk. If you download
Synapo111.sea.hqx without it being automatically de-BinHex4ed you will have to
de-BinHex4 it yourself. Use BinHex4, CompactPro, Stuffit or any other utility
capable of de-BinHex4ing (these are available at most Mac ftp sites). You
should now have Synapo111.sea on your disk. Double click Synapo111.sea and a
folder (SynapoFolder) will be produced containing the 3 files.

We will be continuing to upgrade the program so do tell us any problems,
observations, ambiguities, suggestions or objections you may have.

Have fun with it!
