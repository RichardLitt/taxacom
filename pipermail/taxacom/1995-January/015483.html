Dear David,
I checked the Index Kewensis on CD-rom for you, and Beaucarnea is an existing
genus, but the species name gloriosa isn't in the Index. This is not a 100%
guarantee that it isn't a legitimate name, but there is a big chance for it.
I can send you a list with all the Beaucarnea species if you want, there are
only 25 published names in the Index Kewensis.
The last update for this Index is up to and including 1993.
