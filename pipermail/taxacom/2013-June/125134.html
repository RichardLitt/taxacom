Still makes no sense to have a *requirement* in the code for OA
publication.  There are multiple publication models in place and people
should use whatever one fits their needs!

I also am concerned about using the code of nomenclature as a tool for
enforcing a restricted group views on what publication models are correct
-- even though I actually agree with the group's view.

The code should aim, above all, at stability.  And including this
requirement would not comply with that goal.

Dan
