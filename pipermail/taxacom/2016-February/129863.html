All things are never equal, the illegitimate holotype label is 
meaningless and should be ignored when deciding which Syntype best meets 
the need of the reviser doing the Lectotype designation.

Mike

On 2/28/2016 1:04 PM, Stephen Thorpe wrote:
> Geoff,
> You are conflating all over the place! A syntype is a syntype whether or not the original author added a holotype label to it. It only depends on whether it was designated as holotype in the original description (reference) or not. If no holotype was so designated, but a syntype bears a holotype label (added by whoever, whenever) then, all other things being equal, that specimen should be designated as lectotype, if a lectotype is to be designated. This is to ensure that anybody who wrongly assumed it to be the holotype (and maybe based published taxonomy on that incorrect assumption) did at least use the same specimen as will turn out to be the genuine primary type (lectotype). Only in exceptional circumstances should another syntype be designated lectotype.
