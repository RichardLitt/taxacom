The recent  'no match' response from the ASPT membership query system
(Ericaceae) was due to a problem with the system which *should* be
resolved.  We recently updated the base data and, as a result, some
strings in the menu-guided 'research interest' section might not have
matches, but most should.  The system, which includes access via
name, location, research interest, or 'free form' string query, is
available via the ASPT homepage at

http://www.csdl.tamu.edu/FLORA/aspt/aspthome.htm

(membership)

ASPT also provides access (see 'Systematic Botany' from the homepage
menu) to ASPT publications (Systematic Botany/Brittonia) via string
search.
