The Code covers all names from subspecies to superfamily, so priority
for family-group names is most certainly regulated, in the same way as
for other names at these levels. What has happened in many cases,
however, is that people have not bothered to try to find the oldest
applicable name and junior names have often become those generally used.
The new Code (4th edition) makes provision for such commonly used names
not to be overturned by forgotten older names under certain defined
circumstances. Check it out.
