If you are in to making your own relational database, a very powerful
alternative to FileMaker is Paradox (made by Borland but Licensed to
Corel). I have used this to do everything from print labels, run the the
Cornell web pages (right out of the box) and search pages(
http://henry.ento.cornell.edu ) to developing my own idiosyncratic
relational database. I believe that new versions of FileMaker have
extreme limits on the number of users when it functions as a web server
unless you purchase the expensive "business" version.
