I've been playing with discovering content in BHL, especially  
articles. The result is http://biostor.org/ , which provides an  
OpenURL resolver for discovering articles (you can use this from  
within tools such as EndNote and Zotero).

It's all a bit experimental, but so far it has some 1100 articles from  
31 journals, authored by some 900 authors. I'd welcome comments and  
suggestions (there's a "feedback" tab on the right for this).
