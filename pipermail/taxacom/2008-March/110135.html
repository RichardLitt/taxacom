Here's where I will probably show even more ignorance than usual. If one only has to align five taxa (orang, chimp, bonobo, gorilla, human) is suggested below what is the point if there is no outgroup for analysis? I have seen quite a few analyses that treat the orangutan as the outgroup which means, of course, that the analysis contributes nothing to the orangutan question. In other analyses only one or two species of gibbon or monkey are used. If that were done in morphology one would be laughed out of the room (I take that back, evidently that is no longer the case). 

One of the robust aspects of the orangutan evidence is that if one uses an outgroup to refer to ALL species of monkey and all the lesser apes, any demonstration of absence of the derived state in all these representatives is pretty good corroboration of the derived state for great apes and humans. It will be interesting if the same can be said of sequences where complete outgroup comparison is made, and not just for a few species.

John Grehan

This sort of discussion periodically flares on taxacom (and often with the same participants). Actually looking at the maligned molecular data might be a useful approach to the issue. I've included a small fasta file of hominidae sequences for cytochrome oxidase II.  
I downloaded it from phylota ( http://loco.biosci.arizona.edu/cgi-bin/
sql_getcluster.cgi?ti=9604&cl=61&ntype=1&db=GB159 ), added taxon names to the annotations, and trimmed off the regions of DNA present in only a subset of the taxa (and if this is a controversial step, feel free to get the original data from the above URL and play with it directly). One can load this file in a favorite sequence alignment program that allows manual alignment (MacClade and Mesquite are popular), or even just print out the sequences and truly manually align them, and "go and see that" the reasonable alignment is one with no indels, even though the sequence data are rather divergent (up to 16% pairwise differences) and thus potentially difficult to align. For a mitochondrial protein-coding gene, the lack of indels and thus trivial alignment is what you'd expect. One can also try various "theoretical mathematical models" (Clustal, Muscle, etc.) using reasonable parameter values (such as the program default
values) and verify that these algorithmic approaches return the same results as the gold standard eyeball analysis. Of course, one can set bizarre parameter values to get wacky results, just as one could assert that ears in elephants are homologous with fins in sharks, but barring this, in many cases molecular homology statements will be reasonable and uncontroversial.

Perhaps the morphological characters are giving the correct answer while the molecular data are consistently misleading about hominidae relationships, but if so, the explanation has to come from somewhere other than some innate arbitrariness of alignment. Sometimes alignment IS hard and leads to ambiguous or even erroneous results, but often, especially with exons of protein-coding genes, it's just not that bad. See for yourself.
