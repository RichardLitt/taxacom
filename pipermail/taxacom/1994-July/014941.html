Hi Netters,

        I was curious to know if anyone has developed a coding system for
Reptiles/Amphibians ...  The US Fish & Wildlife service has developed one for
birds based on the first two letters of the common name of the species (ie
American Robin is AMRO etc...) the American Ornithologist Union has a numbering
system that is based on systematics lists (ie American Black Duck, 01330, is
lower than American Goldfinch, 05290).

        Is there a coding system for Reptiles and Amphibians and if there is not
is there any interest in getting something like that started ?
