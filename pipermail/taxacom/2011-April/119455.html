Hi Lena,

 

For my classes on phylogeny (including lab classes) I strongly recommend:

 

* BioEdit

- For DNA and protein alignments (based on Clustal)

-  For checking and manual (?eye?) edition of matrices

 

* Paup/ PaupUp/ TNT

- For parsimony, ML and cluster analyses (molecular and morpho matrices)

Using Windows interface is not so attractive (the menu-based is possible
only in Mac version), so you can use PaupUp to have a user friendly
interface (with menus).

As Paup is not for free, TNT is a good option (it?s free). With TNT it?s
also possible to create numeric (morpho, etc.) matrices.

 

* TreeView and FigTree

Both free and good options to tree drawing.

 

That?s my two cents.

 

Best wishes,

Vitor.
