I was looking for the full text of the Code on the www and found
a text version of the ICZN4 draft at the Biosis website.

This is just to announce this taxonomic community that I have
converted this ASCII version to HTML with a selfmade convertor.
I used a rather straightforward and unfortunatly simple minded
algorithm. Therefore, not all crossreferenced articles
are hyperlinked.
Anyway, this is the result :
