> I'm curious as to how many taxonomists use Mendeley (

I'd like to because it's so good for organizing, but the
bibliography function for manuscripts is so difficult to use
(because you have to edit output styles directly in code, and most

replace EndNote for me, and maintaining parallel systems would be a
pain.
