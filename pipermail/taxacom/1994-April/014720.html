TAXASOFT is an MS-DOS package for editing DELTA data files and running DELTA
programs. It is possible to delete, insert or move around characters, items,
and states, without having to worry about the consistency of the DELTA files.
This first release is still in Beta stage, and is restricted to 1024 items
with 255 characters, 15 states each.

TAXASOFT is available by anonymous ftp from the following Internet hosts.

     Host                   Directories
     --------------------   ----------------------------
     huh.harvard.edu        /pub/software/delta/taxasoft
     life.anu.edu.au        /pub/delta/taxasoft
     spider.ento.csiro.au   /delta/taxasoft

The distribution package consists of text file Download.1st, containing this
information about downloading the programs, and a self-expanding file
taxasof at .exe, containing the programs and documentation. All the files must be
transmitted in binary mode, set by the ftp command `binary'. (Failure to do so
will result in the error message `HeaderC Error' when the .exe files are run.)

Place the file TAXASOF at .EXE in the directory C:\TAXASOFT on your MS-DOS
computer, and expand it by entering TAXASOF at . Start the software by typing
DDMENU at the DOS-prompt.

If you have any problems with the software please contact me. All software is
ShareWare (beta versions). A licensed version can be purchased using the
file order.frm and sending it by Email to the address above.
