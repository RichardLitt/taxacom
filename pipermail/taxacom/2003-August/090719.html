Whew! It was a lot of work but the Wildflower Center has finally gotten
its collection of 11,500 plant images representing 174 Plant Families
and 4,322 species online and linked to a searchable database. See
http://www.wildflower.org/?nd=gallery

If anyone is looking for students projects, we could use some help with
image identification and verification. This work makes a good class
project and can be done remotely via the web interface. Also, any
suggestions for improvements to the site would be greatly appreciated.
