I have completed an updated list (using Michener's 2000 book as a starting
point) of the bee genera of the world, and turned the FileMaker Pro file
into a webpage at

http://entmuseum9.ucr.edu/entmus/beepage.html

The FileMaker file is also available. I would be grateful if people pass
along any needed updates to me as time goes on, to keep the list timely.
Naturally, I'd like to thank Mich for writing the book in the first place
(among many other things to thank him for). Now, if only we could get Mich
to compile a complete list of species... ;-)
