I enjoyed reading Ron's tips on desktop editing, printing, etc, quite
informative. But I understood that Karen is looking for a software to
archive and manage digital images. I use, and highly recommend one that is
promoted as a digital content manager, CompuPic. It is a shareware software
that produces thumbnail images of many different image formats, thus helping
the user to locate the right image quickly. Keywords can be used to catalog
the images, and perhaps some text (not sure). You can download a trial
version from:
http://www.photodex.com/

The company offers a Pro version, which has more features, but I find that
the basic version ($39.95) is already very useful. The basic version offers
some simple image editing that is easier to use and quicker than Photoshop,
which I use for more complex editing. There are many similar software out
there, but this is the one I liked best among the few that I tried.
