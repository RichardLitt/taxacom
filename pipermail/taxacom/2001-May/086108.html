Recently   was  announced  the  release  of  "Syngraph,  an
application  to manage taxonomic names". I have tried it ...
interesting... but too complicated (at least for me...).

I'm  a  professional taxonomist and more or less experienced
programmer,  and would like to present my own  application -
ZooBase, a tool for navigating through literature, taxonomic
descriptions  and  synonymies  of  nominal species. I and my
colleagues, who use ZooBase, are very pleased with it.

To inspect ZooBase download setup file (~3Mb):
http://lithops.mastak.com/zoo/setupz20.exe and run it.

The  usage  is  very simple. Press F1 if you will need help.
Just  type  specific  or  generic  name  (or both) and press
"Enter".  You'll  receive report with information on who has
described or mentioned this species as valid, who treated it
as  synonym  of other species and in what publications (with
complete citations), complete synonymies of every species in
the  database  and  so on.  With cross-referencing, the user
can search all references that include a particular species,
or genus, or references by a particular author, etc.

Using ZooBase user can create database on taxon he studies.

ZooBase is shareware (unfortunately, for certain reasons I'm
not  able  to  distribute ZooBase as freeware). Unregistered
version has some limitations, user can see how ZooBase works
and  decide  if  he  would like to purchase fully functional
version. Registration costs $120.

For  more  info, screenshot, etc., please, visit ZooBase web
page: http://lithops.mastak.com/zoo

I'll  be  happy  to  receive any comments, suggestions, bugs
reports.
