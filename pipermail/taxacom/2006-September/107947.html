I tested this out for two ants, Cataglyphis and Formica rufa, the first ant
described by Linnaeus.

I find the results not satisfying:
1. Only the name typed into the system is given, no synonyms.
2. Only the author is given, no year, page, publication
3. Under Articles (the menu where the name information is displaye), a
random list of unliked papers on any subject (none on systematics) is given,
and this all in an incomplete citation, without the journal, etc.
4. Web Link: only one link is given the biology browser, which delivers no
results.
5. Advanced search does not work
6. No children of a parent is available

There is much more detailed stuff out there (Hymenoptera Name Server, ITIS,
ubio, antbase, etc.) of which zoobank will take advantage.

An important tool that needs quiet some work

Donat Agosti
