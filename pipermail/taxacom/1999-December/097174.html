I have posted scanned versions of Newsletter 11 to the Web at
http://biology.usu.edu/herbarium/manual/newsletter/news_11_1.htm
There is a link to it in the manual home page:
http://biology.usu.edu/herbarium/manual/
which permits less typing on my part and yours - and hence, fewer
possibilities for errors. Having used Microsoft Publisher to develop it, we
cannot easily convert the original file into a Web document.  Sorry about
that!

The newsletter is not written for posterity, but a few libraries have
requested copies. They are welcome to print off a copy, as are individuals
who would like to keep a copy for their personal use (please note that it is
copyrighted).  We will send out a complete set of newsletters to anyone
sending us a request accompanied by $15 (US dollars), but we would much
rather not do so.

We have not posted the first nine newsletters. We may do so, but it would
take time without helping us complete the project, consequently it is a very
low priority task.
