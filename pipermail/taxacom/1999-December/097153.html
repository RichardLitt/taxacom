For anyone using or interested in using the suite of cladistic programs
NONA, PIWE, DADA, CLADOS, and WinCLADA, a new users' group e-mail list
has
been established. This list is a forum for discussing the use of these
programs, asking questions, exchanging tips, etc.

Anyone who has used these programs knows that their help documentation
is
not extensive.  This list will be a place where people can share
experiences to ensure that the programs are used properly, the results
are
interpreted correctly, and the full potential of the programs is
realized.

The list is not intended to be a systematic theory or a computer
programming
discussion group, except to the extent that these issues are pertinent
to the use of the software.

Sign up at http://henry.ento.cornell.edu/CUIC/cladsoft_lst.htm

Please pass this message to anyone you think might be interested.
