The World Checklist of Monocotyledons looks like an excellent
resource. Do you plan to make it accessible via web services so that
others can query the database without having to go through the web
interface?

For example, with a web services interface (or a URL API along the
lines of ITIS or IPNI) it would be possible for tools such as my
Taxonomic Search Engine
(http://darwin.zoology.gla.ac.uk/~rpage/portal/ ) to search the World
Checklist of Monocotyledons. Users could also call the database from
Excel spreadsheets to check the spelling of names, and so on. ePic
looks as though it could be easily adapted to serve data in this way,
given that it already can email data in a variety of formats.
