> taxacom at lists.ku.edu<mailto:taxacom at lists.ku.edu>> wrote:
> A new combination is defined in the Code Glossary as:
> "The first combination of a generic name and a previously established
> species-group name."
>
> Changes in rank from species to subspecies (or vice versa) will not
> qualify as new combinations as these changes do not involve the combination
> with the generic name.
>
> /Thomas
