A new combination is defined in the Code Glossary as:
"The first combination of a generic name and a previously established species-group name."

Changes in rank from species to subspecies (or vice versa) will not qualify as new combinations as these changes do not involve the combination with the generic name.

/Thomas

> It seems perfectly Code compliant to me.
>
> Tomiyama (1936) treated cirratus Blyth, 1860 as a subspecies of 
> Taenioides gracilis (Valenciennes, 1837) - the oldest available name 
> for the species - and as such the name cirratus retains the authorship 
> Blyth, 1860 when treated as a subspecies rather than a species. As far 
> as I can understand from the above Tomiyama (1936) did not describe a 
> new taxon.
>
> The correct name for the taxon is Taenioides gracilis cirratus (Blyth, 
> 1860) as stated by Tomiyama (1936).
