 I have obtained a couple of PDF publications that were sent to me, made
some from TIFF files sent to me and have also scanned in some to send to
others and agree that this would be a welcome resource.
 I found that PDF files from scanned documents can be quite big but when
scanned using Lurawave technology (LDF) are much more manageable. For
instance one document was 33mb as a PDF but something like 1.3mb as an LDF
file. The source for Lurawave programs is
    LuraTech, Inc.
   1030 Curtis Street, Suite 201
   Menlo Park, CA 94025
   E-Mail: info at luratech.com
   http://www.luratech.com
 The cost has gone up to US$99 for the higher specification LuraDocument
Capture Professional program (you can still download a free Lite version
from http://194.231.34.35/products/download/fs_e.html) and you can use the
same program or the freeware Irfanview with the LDF plugin to view or print
the files. Irfanview can be obtained from http://www.irfanview.com as a
download. The nice thing  about using Irfanview is that it is easily
available and reads multiple graphics formats so makes an ideal reader for
many purposes.
