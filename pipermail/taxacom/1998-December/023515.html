Dear Taxacomers,
The October 14th Taxacom posting by Jim Beach, asking for opinions and
advice on designing a new www interface to natural history collections
data elicited a long thread, still not dead, which has focussed mainly
on the issues of 1) whether or not to put select collections data into
public-access interfaces (species protection, resale value of the data);
2) data quality and integrity (data audit trails); and 3) technology
choices (esp. vis a vis cost and time-to-product).

If you would like to retrieve the entire thread to date, send the
following to listserv at cmsa.berkeley.edu. Make sure that each line is
preserved exactly as written below (in particular, make sure the long
lines beginning with "search" and "index" remain as one line each).
There are now around 55 postings.  It is not necessary to be subscribed
to Taxacom in order to retrieve the archived postings.
 Peter
