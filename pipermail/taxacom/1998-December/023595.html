     A multiauthored DELTA Intkey data set has been developed for the
     mushroom genera 'Leccinum and Phylloporus in Costa Rica.'  The URL is:
     <<http://www.nybg.org/bsci/res/hall/deltaindex.html>>.  Access over
     the web requires the test version of Intkey and Windows95/NT or later.
     Data set can be downloaded for use off-line.

     The authors are: R. E. Halling (New York Botanical Garden, Bronx, NY,
     USA), G. M. Mueller (Field Museum, Chicago, IL, USA), and M. J.
     Dallwitz (CSIRO, Canberra, Australia).  We welcome any comments,
     suggestions or critique.  Please address same to Halling (author of
     this posting).

     Thanks for your attention and best wishes for a pleasant holiday
     season.
