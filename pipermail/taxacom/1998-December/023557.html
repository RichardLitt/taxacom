The Internet Directory for Botany has a page dedicated to image sites
at:

http://www.helsinki.fi/kmus/botpics.html

The largest of those listed, with over 16k images (ca. 2900 species),
is CalPhotos site (UC Berkeley Digital Library Project) at:

http://elib.cs.berkeley.edu/photos/flora/

As indicated by the 'about' section of this site, it represents a
'shared' exercise with images and associated data contributed by
several photographers as ASCII files and processing managed by a
UNIX-based DBMS (Informix Universal Server).

Similar in concept, but smaller (ca. 6k images) is the Vascular Plant
Image Gallery at:

http://www.csdl.tamu.edu/FLORA/gallery.htm

which is based on a full text index of image file URLs.  Links
with any string in this index can returned using the query URL:

http://www.csdl.tamu.edu/FLORA/cgi/gallery_query?q=ecuador

with 'ecuador' replaced by a query term of interest (name, structure,
etc.) that might be present in the index.
