Dear taxacomers,

Thanks for all those who replied me and tried to give some light to this
subject. I will reply each one as soon as possible, but many thanks in
advance.
I received very interesting suggestions (WinClada, NoNa, TNT, PAUP,
AutoDecay, and a script to NoNa - thanks Fernando!) and some of them
were very successful.

The only problem is, yet, to assign a cost matrix (gaps, transitions,
transversions) to the analysis. Does anyone know if NoNa allow to assign
a cost matrix? And, using NoNa, is it possible to use more than one data
set (gene1, gene2, morpho) in separated data files (just to avoid having
to join all the data into only one file)?

Many thanks again,
Vitor.
