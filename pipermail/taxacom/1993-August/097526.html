LIST OF USEFUL MAILGOPHER database searches
-------------------------------------------

A list of databases which can be searched using mailgopher is currently
being prepared. This list will be updated on a monthly basis (if our
work schedule permits) and posted on the network.

To carry out a search or retrieval, send email to


      mcbserve at nusunix2.nus.sg (or mcbserve at nusunix1.nus.sg)
OR
      mailgopher at nusunix1.nus.sg

Leave the Subject line blank
Precede the body of the request with the string "GOPHER"
Copy one the following blocks of Host, Port, Path, Type... exactly,
if possible, without trailing spaces, or control characters, etc.
If the entry is a search type=7, add keywords for searching in one line eg.

keyw=keyword1 keyword2 .....

For some gopher sites, boolean searches using "and" and "not" and partial
literals (eg. keyw=Escheri*) are possible; whether they are or not, will
have to be determined by trial and error, because it is not specified.

IMPORTANT NOTES:
Many of these Gopher databases are created and maintained voluntarily by
maintainers throughout the world and are subject to change without
warning. If you have difficulty getting something back, try mailgopher
to the root directory of the host first, eg. use type=1 and path=1/
(try the default port 70) and slowly work your way down the directory path.

This list presupposes that the user already knows about the database.
If not, try mailgopher to the root directory of the host as described
above and you should find information describing the database available for
retrieval.
