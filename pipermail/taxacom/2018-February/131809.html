Interesting. No opinion either way. The arrangement with the Remipedia and
insects seems to be molecular. wonder if there is any morphology to support
it. Remipedia are blind crustaceans found in coastal aquifers which contain
saline groundwater. Extant species distributed (as currently known)
Caribbean-Canary Islands-Western Australia. Absolutely classic
biogeography.
