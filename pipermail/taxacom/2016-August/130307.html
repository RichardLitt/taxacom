Rod Page wrote (and Paul Kirk concurred):
-----
I'd argue that focus sing on getting a list of names alone is not enough,
I'd spin the problem around and say we should get the taxonomic literature,
because that contains the names linked to evidence.
-----

That's good, because it saves me having to do it :)

All I need is to know what identifiers you guys are using for the same
names as are in my system, and I can provide users (humans or even
machines) with a means to hop across to your systems to view and/or grab
relevant literature citations, view text online, etc. as available.

For example on the IRMNG page for Aagaardia protensa Sæther, 2000 (a
chironomid midge, name from Systema Dipterorum via the Catalogue of Life in
2006), I have browsed the Thomson Reuters ION database for the relevant ION
identifier which 1451386, which I now hold in my system along with 300,000
others. Knowing this, and also the fact that Rod's BioNames database also
uses the same identifiers, on my IRMNG taxon page for this species:

  http://www.irmng.org/aphia.php?p=taxdetails&id=10561410

I can automatically provide a "deep link" "To BioNames Datbase" as follows:

  http://bionames.org/urn:lsid:organismnames.com:name:1451386

and as Rod put more of the biodiversity literature online, the overall
system becomes more and more capable (basically I have outsourced that
element of the work to him, thanks Rod...)

I could do the same with fungal names if I had the Index Fungorum
identifiers as well (and so on), although uploading these (if possible)
will probably be a task for someone else as I no longer have access to the
large computers on which to do the matching (down to a little laptop these
days...)

Anyway, a good example of distribution of effort (within a linked
environment via the web) meaning that one system does not necessarily have
to do everything to still be useful.
