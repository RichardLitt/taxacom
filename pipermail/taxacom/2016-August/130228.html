There are many awkward issues involved here. Every existing option has significant disadvantages of one kind or another. What we actually need is something along the following lines (nothing exactly like it seems to exist at present): 

A database open to everyone to contribute (publicly displaying when a record was created and who by), but which has the following two features: 

(1) Every little pedantic formatting detail must controlled and fixed in advance by the database, leaving no formatting options for contributors to argue over; and

(2) there must be a flag option (publicly displaying when the flag was set and who by) for any record, to be used if there is some sort of problem with that record, possibly with an explanation field to go with the flag, but this would require moderation.

Cheers, Stephen
