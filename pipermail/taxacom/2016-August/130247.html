Tony asked "So if LepIndex does not fill the niche (as a block of expert reviewed, re-usable content), I wonder what does..."

Nothing does, that's the problem currently! Data for every taxon does have to be individually compiled at some stage of the process, and it simply hasn't been done yet for many taxa in a robust way. The only way it can be done in our lifetime is to open it up for anyone to create a clearly predefined record for all the information that we want, and to allow annotation for flagging errors. It will take time, but there is little point in propagating unreliable data like LepIndex on a large scale.
