Hi Mike,
Yes, I tend to agree that the Hoser thing needs to be dealt with. While it is true that the Code is only followed "voluntarily", this is problematic in that it can cause division within the taxonomic community (even excluding Hoser) with some people taking the opportunity to publish Code compliant nomenclature to counter other people's non-Code complaint nomenclature, which is all a waste of time! Note that, in this case, we have people taking the opportunity to publish Code compliant nomenclature to usurp other people's (Hoser's) Code complaint nomenclature! This is an even bigger waste of time! At any rate, editors should reject submissions which are not Code compliant (or which contain nomenclatural acts that are a waste of time, as in the present case), but, unfortunately they often don't seem to be able to judge, or to care.
Cheers,
Stephen
