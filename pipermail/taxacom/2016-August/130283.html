Given that taxonomic databases have been a recent theme, readers might be interested in a feature I’ve added to BioNames http://bionames.org<http://bionames.org/> that displays the original description for a species (where possible). Details on http://iphylo.blogspot.co.uk/2016/08/displaying-original-species.html

[http://media.eol.org/content/2011/08/11/16/63624_88_88.jpg]<http://bionames.org/>

BioNames<http://bionames.org/>
bionames.org<http://bionames.org/>
BioNames is a database of taxa, texts, and trees. It includes taxonomic names for animals (and other organisms covered by the ICZN), full text literature from BioStor ...




Some examples:

http://bionames.org/names/cluster/1578789
http://bionames.org/names/cluster/2264732
