As I mentioned, the Catalogue of Life sources its spiders taxonomic names
component from the World Spider Catalog so if you download CoL, you should
get that element of the data (presumably there is an option to filter by
data source therein). I don't think you can download the entire database in
its native format but that is common to most such systems.
