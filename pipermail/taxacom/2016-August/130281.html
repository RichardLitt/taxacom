Given that taxonomic databases have been a recent theme, readers might be interested in a feature I’ve added to BioNames http://bionames.org that displays the original description for a species (where possible). Details on http://iphylo.blogspot.co.uk/2016/08/displaying-original-species.html

Some examples:

http://bionames.org/names/cluster/1578789
http://bionames.org/names/cluster/2264732
http://bionames.org/names/cluster/1205543
