Dear Colleagues,
The Symbiota2 project team invites you to attend the next open discussion session concerning the Symbiota2 project. It will be on:
TIME: Wednesday, September 15 at 10.30 am MDT[1]
Location: https://us02web.zoom.us/j/82515787249
The session will start with an overview of progress, including identifying a target date for release of version 1 and an explanation of how other developers can add functionality to Symbiota2.
Version 1 is to have the functionality of Symbiota at the time the S2 project started but with a structure that enables any developer familiar with occurrence-based biodiversity informatics to add to its abilities.
Please encourage your favorite developer to attend!
More information on Symbiota is available through the following websites:
Symbiota2<https://www.symbiota2.org> provides information about the project, including the original proposal, view progress, videos of previous discussion sessions<https://symbiota2.org/interactions>, and links to help pages.
Demonstration websites
Frontend (user interface) demo: https://demo.symbiota2.org/
Backend (raw data access) demo: https://api.demo.symbiota2.org/docs/
Code: https://gitlab.com/symbiota2/symbiota2 (check out the README for developer-centric info).
Issues: https://gitlab.com/symbiota2/symbiota2/-/issues. We cannot promise that all the posted issues will be addressed before the project ends, but the list will help determine our priorities.
Sincerely,
Mary Barkworth for the Symbiota2 Project team
Curtis Dyreson, Neil Cobb, Will Pearse, Evin Dunn, Darius Dumel, Ali Rezaee, Gary Fehlauer
