I've noticed sustained interest in X Window software for PCs in our
community.  For those interested, there is a review of four PC X
Server software packages in the current issue (August 94) of Advanced
Systems - a trade magazine for client/server computing.  The review
recommends 'Hummingbird eXceed 4 for Windows.'  The list price is US$545.

I've tried three PC X server packages in the recent past including the
Hummingbird software which is my current choice.  Installation and
operation on a Windows 3.1 PC was a breeze and for three weeks it has
functioned flawlessly.  The integration into Windows is excellent.

For PC (Windows) X server software, one realistically needs a minimum of 8
MB of RAM, a 486 class or faster PC, the Winsock interface configured as
part of the network drivers, and a network connection.

Canada).
