I have placed a zipped and unzipped ascii file of a database that lists
country, state (or equivalent), county (or equivalent) and, for the US, FIPS
code at stipoid.convert at cc.usu.edu.  All U.S. counties, Canadian provinces,
and Mexican states are included.  Coverage of other parts of the world is
spotty.

The files are available by anonymous FTP.  The only quirk that I am aware of
is the manner in which one changes directory on our VAX.

FTP cc.usu.edu
user: anonymous
password: your email address
cd disk$util:[stipoid.convert]
get regions.asc [unzipped version]
lo

Presumably for the zipped version one should set file type to binary first
of all.
