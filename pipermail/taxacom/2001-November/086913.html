Announcement:

- Email address for LVB support;
- Web page for LVB;

(1) EMAIL ADDRESS FOR LVB SUPPORT

The email address for LVB support has changed. It is now:

Daniel Barker <db2 at sanger.ac.uk>

(2) LVB WEB PAGE

The LVB Web page has moved. It is now at:

http://www.sanger.ac.uk/Users/db2/lvb.html

(3) FURTHER DETAILS

The program made available on the Web page as source code and binaries has
not changed at all during the move. But I have updated the online manual,
and the release notes and some comments in "makefiles", to refer to the
new email address and URL.

The changes reflect my move to the Sanger Centre, where I have been
working since August this year. The old addresses were at Edinburgh
University, where I have not been based for some time.

I apologize for any disruption. Change was inevitable at some point. The
new Web page is under my direct control, which will make it easier to
update. A new version of LVB is planned in 2002.

Finally, I would like to say many thanks to Steve Yewdall and Ian GIlbert,
who helped with the LVB Web page whilst it was in its former location(s)
at Edinburgh University.
