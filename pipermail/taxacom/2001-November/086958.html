Dear Taxacommers,

Today we have released Carnoy 2.0, an easy-to-use software package to
carry out measurements on digital images. It's in use by many
universities, botanical gardens and research institutes world-wide (such
as NASA, University of California and Fairchild tropical gardens).
Carnoy doesn't have all the features of some very expensive image analysis
programs, such as filters and plugins. But for scientists who want to
measure on
digital images, Carnoy has an uncluttered and intuitive interface, which
enables the user to be productive within minutes, and without reading a
300 page manual.
The two main features of version 2.0 are its redesigned interface and
its new pen tool to draw freehand selections.

Carnoy is available for Windows (95, 98, ME, 2000, XP) and Mac OS X.
More information is available on the Carnoy website (www.carnoy.org).
Try it out!
Be sure to read the readme file and the new manual for more information
on installing and using Carnoy 2.0!

The update is free for users of Carnoy 1.0!

Carnoy is $15 shareware (if you cannot afford this, please, contact
peter.schols at bio.kuleuven.ac.be). It is available for download on the Carnoy
website.
http://www.carnoy.org
