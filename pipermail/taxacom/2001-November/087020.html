I am using still database dbase IV.
When I set up command "carry on" and I insert record anywhere in the
database  by pushing one key "F7" it carry all the information from previous
record to new one and I can retype only fields like Date of collecting,
locality, etc and save me all the typing.

The *.dbf file is easily imported to any database,spreadsheet or even
wordprocessor, is very universal.

Most difficult is to design. What fields do you need and size. important is
that you see all the fields on ONE screen.
