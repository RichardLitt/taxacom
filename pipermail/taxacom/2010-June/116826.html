As I pointed out earlier, the easiest way to clarify this would be 
to add (real-life) Examples to the Code. The botanical Code has
three Examples on this topic (Art. 32, Ex. 3-5), with Ex. 4 
looking to be most relevant here:

   Ex. 4. ?Crepis praemorsa subsp. tatrensis? (Dvor?k & Dad?kov? 
   in Biol?gia (Bratislava) 32: 755. 1977) appeared with 
   ?a subsp. praemorsa karyotypo achaeniorumque longitudine 
   praecipue differt?. This statement specifies the features 
   by which the two taxa differ but not how these features differ 
   and so it does not satisfy the requirement of Art. 32.1(d) 
   for a ?description or diagnosis?.
