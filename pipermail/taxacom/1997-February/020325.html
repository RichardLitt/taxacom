There are several databases available for the identification of tropical
woods using the Dallwitz's INTKEY program.  These are databases which
were developed in DELTA format, and are now accessed via INTKEY.

The easiest to obtain is Richter's Trade Timbers which can be obtained by
FTP or Net Browser at the following URL, at no cost:
  ftp://ftp.keil.ukans.edu/pub/delta/wood
Below is the document, DOWNLOAD.1ST, which accompanies the file at the
above URL.

I understood that the IAWA has converted its large database to DELTA
format also.  I do not know how you can obtain it, but I have the
following reference concerning the conversion:
  de Pernia, N. E., and Miller, R. B. (1991). Adapting the IAWA list of
    microscopic features for hardwood identification to DELTA.  IAWA
    Bulletin n. s. 12, 34-50.

An MS-DOS INTKEY package providing interactive identification and information
retrieval for trade timbers, in German or English, is available by gopher or
anonymous ftp from the following Internet hosts.

     Host                   Directory
     --------------------   -----------------------
     muse.bio.cornell.edu   /pub/delta/wood
     [The above line is now incorrect; see the above URL.]
     spider.ento.csiro.au   /delta/wood

The distribution package consists of a text file Download.1st, containing
this information about downloading the package, and a self-expanding file
wood at .exe, containing the data. The files must be transmitted in binary mode,
set by the ftp command `binary'. (Failure to do so will result in the error
message `HeaderC Error' when the .exe file is run.)

If you do not already have the latest version of the interactive
identification and information retrieval program, INTKEY, you will need to
obtain the file delta1 at .exe from the msdos subdirectory. This file contains
INTKEY.EXE and its documentation.

Copy the file WOOD at .EXE into the directory C:\WOOD on your MS-DOS computer,
and expand it by entering WOOD at . Start the program by typing WOOD (English
version) or WOODDD (German version) at the DOS prompt.

Updates are announced on the Internet via the Taxacom mailing list. To
subscribe to Taxacom, send the message
    subscribe taxacom your-first-name your-last-name
by email to listserv at cmsa.berkeley.edu.

The DELTA files from which the package was generated are available from the
author.
