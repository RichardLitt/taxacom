The problem I have is with the search function. I am happy with the new
online viewer which is faster, but the search page is not useful. In my
browser I can practically not use the search function. Everything seems
very much distorted. There are screens where the search box is hidden
behind some colour bars. Also the list with the results looks much worse
than before. In the old system the results set was shown in a very clear
form and very useful.
I had used the search function of BHL very frequently, but now with the
new system I will certainly have to look for another method for finding
literature.

The BHL-Europe site is still worse, there I cannot even insert the search
items in the initial search page because moving pictures of books appear
directly in front of the search box and do not allow me to type a word in.
The BHL-US site does not have this extreme problem.

So in summary, the BHL search page and the results set is much worse (and
it had been very good before!), but the viewer is much better and has
improved considerably. It is very good that the URL deep links to the
pages inside books have remained the same, so that links from AnimalBase
did not become outdated.

Francisco
