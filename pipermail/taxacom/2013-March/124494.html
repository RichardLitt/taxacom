Hi Taxacomers,

I came across a question regarding different name categories and their relative numbers. If one roughly differentiates name categories in the species-group like descriptive names, geographic names, commemorative names and 'other names', is there any statistics available about the relative numbers of these name categories in a certain group or estimates or counts across larger taxa? It would also be interesting to subdivide these larger categories even further. Another question would be if the proportions of name categories change over time (which I would expect), and if there are numbers available to document the change, at least exemplary. I wonder if any of the existing databases allows to filter for name categories ...
