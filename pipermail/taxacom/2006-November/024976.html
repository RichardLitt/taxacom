Those peoples working with Ekman specimens should take note that some 
collection numbers of this prominent botanist beginning with an H may be found 
in Ekman Herbarium (EHH) without the H.  The reason for this is unknown.

So, while searching the online database, please use both manners in order to be 
sure to find the specimens (nomenclatural type and others) you are looking for.  
A note about this has been added to the search page
