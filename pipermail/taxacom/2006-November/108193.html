Atlantis Botanic Gardens Taxonomic Database

For a few years now we are working with Atlantic Botanic Gardens and we 
are very happy with it.
As far as I know, it is the only taxonomic database presenting the 
taxonomic data in a tree structure,
(as well as the other related objects) see some screens on our website:
http://botuweb.bio.uu.nl/atlantis/screens-e.htm

It is a Progress Objectstore database both accessible from Windows as 
well as the Internet, using
the most advanced technology (objectstore, verity, Atlantis platform)

I will be happy to answer questions about it and if needed I will add 
information to the web site to
make it all clear.
