Dr. Richard Straw (Penstemon) developed a very nice program for
printing herbarium labels. It is simple and easy to use. Here is some
information.

Herbarium label program prints standard 3 by 5 labels to dot matrix
printer. DOS 3.3+, not Windows or Mac. Distributed as shareware (try it
out, pay suggested fee if satisfied). If interested contact on internet to
straw at tao.sosc.osshe.edu with required disk size.

It is not a data base, but he might be persuaded.
