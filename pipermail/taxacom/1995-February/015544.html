        To my embarrassment an user found that the program would not export
GIS type files because I had forgot to include a database called gismodel.
it was supposed to be part of the gfiles.zip. I've put a corrected
gfiles.zip onto the Taxacom of FTP. If you're using the program, obtain the
new file and simply unzip it after placing it in the directory containing
the RESEARCH INTERFACE. This should solve the problem. I guess the program
had what commercial developers call an " undocumented feature "!
