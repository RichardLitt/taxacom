LVB is a free phylogeny program that uses the simulated annealing
heuristic to seek parsimonious trees. See

http://www.icmb.ed.ac.uk/sokal.html

A ready to run version for OS/2 and a very brief "man" page for Unix
are now available, but not yet on the Web. If interested in either
of these, please e-mail me and I will send an attachment. The OS/2
distribution is a ZIP file, 106KB in size. The "man" page
distribution is a TAR file, 10K in size.

Thank you,
