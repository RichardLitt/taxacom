For the western states (Rockies and west), Martin Wefald has made available
a program called trs2ll.exe which converts tn/rg/sn data to lat/long (and
vice versa.  It is available via anonymous ftp to cc.usu.edu

Once logged in, change to the necessary subdirectory by typing

cd disk$util:[stipoid.convert]

Remeber to set file type to binary before downloading.

This repeats my earlier message, but some may have missed it, hence the
repetition.  Mary Barkworth.
