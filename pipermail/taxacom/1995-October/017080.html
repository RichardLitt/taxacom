DIANA is an interactive MS-DOS software management system for editing DELTA
data and directives files and running DELTA programs. It is available by
gopher or anonymous ftp from the following Internet hosts.

     Host                   Directories
     --------------------   ----------------------------
     huh.harvard.edu        /pub/software/delta/diana
     spider.ento.csiro.au   /delta/diana

The distribution package consists of a text file Download.1st, containing this
information about downloading the programs, and a self-expanding file
diana at .exe, containing the programs and documentation. All the files must be
transmitted in binary mode, set by the ftp command `binary'. (Failure to do so
will result in the error message `HeaderC Error' when the .exe files are run.)

Copy the file DIANA at .EXE into the directory C:\DIANA on your MS-DOS computer,
and expand it by entering DIANA at . Start the program by typing DIANA at the DOS
prompt.

If you have any suggestions or problems with the software please contact me.
DIANA is freeware - it may be used, copied, and distributed freely, provided
that no price or fee is charged for it.
