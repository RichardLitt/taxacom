Davide Sassi's question does not concern the gamma 1 statistic
applied to the lengths of a set of trees.  Rather, it concerns
PAUP's goodness-of-fit statistic applied to a given character
with respect to a given tree.

This goodness-of-fit statistic is new since PAUP 3.1, and is not
explained in the PAUP 4.0 draft manual nor AFAIK anywhere else.
Thus, Davide should ask in the PAUP Tech Exchange forum how this
statistic is calculated, so David Swofford can explain it for
the benefit of all PAUP users.  The PAUP Tech Exchange forum is
on http://paup.csit.fsu.edu/.
