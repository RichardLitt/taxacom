>Is this a request for Goloboff-fits (p. 90 of PAUP* beta documentation,

Nope.  Goloboff fits are an option of the PAUP command PSCORES.

The PAUP command DESCRIBETREES / DIAGNOSE=YES produces a table
for each tree.  For each character on that tree, the table lists
a character consistency index, retention index, homoplasy index
...and "G-FIT".
