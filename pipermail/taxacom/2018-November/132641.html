Dear Taxacomers,

Please note that following requests, the deadline for submitting symposia
proposals for the biodiversity_next
<https://biodiversitynext.org/call-for-symposia/>conference in Leiden, The
Netherlands, October 2019 has now been extended until *Sunday, Dec. 9th. *

As there appeared to be a sporadic issue with the submission form, anyone
who submitted but did *not* receive an automatic acknowledgement reply from
the system should please consider resubmitting. Acknowledged submissions do
not need to.

Also, please note that this call is for symposia and session proposals. The
call for contributions will be made at a later date.

Thanks and regards,

Arturo H. Ariño
