John,

I have been playing with this concept too. My keys that are published on the web
work much faster running locally from a CD-ROM. I have found that if I put all the
information into subdirectories and have a simple start.htm file that provides the
first link at the top level then users just click on the start.htm file and
Windows95 (which is the environment I use) automatically launches the user's default
web browser to load the file. Then the whole things just runs as if it were on the
web, but without the wait.

Ron Stinner, manager of IPM-Net USA, has commented recently that publication of
something on the web so it is free to users does not reduce the demand for the same
thing on CD-ROM (even at a cost) but serves the alternative purpose of providing
free advertising of the product. Potential purchasers are able to try it out first
on the web and, if they find it worthwhile, will then purchase a copy in order to
have it run faster. The down side of this is that it is possible to keep a web
version up to date while copies made available on CD-ROM go out of date as soon as
the web version is updated.

Murray
