1999 
The Specify Software Project is delighted to announce the availability of
Specify, a comprehensive biological collections management system.  Specify
1.0 is available for downloading from the project web site at:

        http://usobi.org/specify

Printed documentation in the form of a user manual is available as is full
on-line help within the application.  Technical support is available for US
collections institutions who use Specify as the primary collections
cataloging package.

Specify is the follow-on package to the MUSE collections management system
and is supported by a grant from the US National Science Foundation,
Division of Biological Infrastructure and by the University of Kansas.

Please see the Specify web site and user documentation for more information
about the features and functions of the Specify package.
