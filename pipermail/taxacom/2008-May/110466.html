Dear NaviKeyUsers,

A significantly improved version of NaviKey (ver. 5.0) is released and 
now available for download at NaviKey home (http://www.navikey.net/).

NaviKey is an online identification tool for DELTA data 
(http://www.delta-intkey.com), maintained and, from 2007 on, further 
developed at the IT centre of the SNSB, Munich. Authors of the releases 
since ver. 4.0: Dieter Neubacher and Gerhard Rambold (University of 
Bayreuth, Germany).

NaviKey may be used as:
a) a Java applet providing the contents of DELTA files;
b) a stand-alone Java application for both accessing DELTA files and a 
PostgreSQL versions of DiversityDescriptions databases;
c) a module ("plug-in") of the Java-based DiversityNavigator database 
client (http://www.diversitynavigator.net) for DELTA 
files/DiversityDescriptions databases.

New features are:
- Implementation of options for taxon images and information
- NaviKey configuration file in XML (NaviKeyConfig.xml)
- Implementation of "Implicit values" directive

For exploring the new image options visit:
http://www.navikey.net/DeltaSampleData/index.html
http://liaslight.lias.net/Identification/Navikey/World/index.html

For further Web Projects with NaviKey in service visit:
http://www.navikey.net/webprojects.html


IMPORTANT:
To run NaviKey, the most recent version of JavaTM Runtime Environment 
needs to be downloaded and installed first. For use of image and 
information functions, Java version 6.0 or above is needed. Selecting 
any item in the bottom right panel with a right mouse click will bring 
up a context menu with links to images, taxonomic information, and web 
services. Images from reliable sources are available, if the button is 
highlighted in green. Make sure that the address of the respective web 
site is included in the list of allowed sites of your web browser's 
pop-up blocker settings.
