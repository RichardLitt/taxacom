Dear all,

This might be of interest to all scientists working with microscopic  
images:

LEUVEN, Belgium ? May 6, 2008 ? Orbicule today released  
Macnification, its brand new, Macintosh workflow solution for digital  
microscopy.
Macnification enables scientists to import, organize, find, annotate,  
analyze, adjust, compare, visualize and publish microscopic images.

Macnification highlights include:
- An image database, including the ability to organize images in  
folder and smart folders
- The ability to view, edit, save and search for image metadata
- The possibility to work with image stacks, including a spectacular  
stack view
- Multiple analysis features for measuring length, area, perimeter,  
circularity and color contents
- Measurements auto-save: measurements are always saved alongside  
images, making it possible to review and change them later
- One-click exporting options to Excel and Numbers
- The possibility to create movies from a series of images
- Many options for adding scale bars to images
- A convenient mini browser to easily export images to other  
applications
- An innovative light table that allows for image comparisons

Availability
A fully functional 30-day trial version is available at: http:// 
www.macnification.com/download

More information
The Macnification website contains a detailed list of features and  
also provides prospective users with six demonstration movies,  
outlining Macnification's highlights and workflow.
Please visit: http://www.macnification.com/screencasts
