2014 
The Specify Software Project is pleased to announce an open demo  site and preview of our upcoming release of Specify 7 -- Specify for the Web.

Specify 7 moves collections data curation to the web. It makes collections records accessible on any computing platform with a web browser, including desktops, tablets, and smart phones.

We invite you to check out Specify 7, to see what you think, and to offer  feedback.

Specify 7 will be available within a few months as release 1.0. It uses the same database design as Specify 6-no data conversions will be needed, and Specify 7 will run simultaneously with Specify 6 on the same collection database. In addition, we designed Specify 7's data form interface to use the same custom specifications  currently used for Specify 6. The look and feel of the new customizable data forms are virtually identical to those of Specify 6.

The initial release of Specify 7 will include several core capabilities but not all those currently found in the Specify 6. The initial release of Specify 7 will support collection data entry and edit through the data forms interface. It will also support structured queries, express or simple search, georeferencing with GEOLocate and mapping with Google Maps. Specify 7 release 1.0 also supports images as file attachments for browsing and displaying. 

Collection management transactions,  such as loans and accessions, the Workbench interface, printing, multi-user-class security, and account administration will not be present in the initial release of Specify 7 within a few months. Those functions can all still be handled through Specify 6.

Take a test drive at the Specify 7 demonstration site:

We invite you to send e-mail with  comments and suggestions to: specify at ku.edu.

The Specify Project is delighted to provide this upgrade path to hosted and shared databases for your institutional data and for collaborative projects--on the web. Specify 7 will provide ubiquitous access to your collection's data without any client software installation.
