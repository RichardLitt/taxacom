Short answer to which Code applies to Chromista is, it depends, since
Chromista (per Cavalier-Smith usage, as adopted by CoL) includes some
groups established under the zoological Code - examples  Ciliata,
Foraminiferida - and others under the botanical Code, i.e., Algae by
another name, such as diatoms, chrysophytes, phaeophytes (brown seaweeds)
and more. A few groups notably dinoflagellates and eugenids have members
named under both Codes, which also causes some problems, maybe others can
comment further...

Regards Tony
