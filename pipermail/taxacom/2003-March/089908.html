In general, the metaphor of using nature for "computation for free" is
very appealing.  Take "DNA computing" as an example with some potential
for interesting work beyond toy problems: using biomolecules in
solution for combinatorial search.  If you wanted to solve a phylogeny
problem using DNA computing (like maximum parsimony), the primary
difficulty is how to encode the search space.  In principle, however,
there is no a priori reason why this would be more difficult than any
other combinatorial problem that has been solved this way; it's the
traveling salesman problem writ large.  Having multiple optimal
solutions isn't really a problem either (at least in principle); just
run the experiment multiple times.  Have a look at the DNA computing
literature; papers by Richard Lipman and Leonard Adleman may be of
particular interest.  I wouldn't be surprised if someone is working on
phylogeny problems in the DNA computing field.
