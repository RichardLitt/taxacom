I doubt that (m)any botanists, nevermind bacteriologists, fully grasp the gigantic mess that is zoological nomenclature/taxonomy. LSIDs, ZooBank, etc. do little or nothing to improve that mess. There are far more important things to be done first, like just sorting out and linking together names and literature, something along these lines (http://species.wikimedia.org/wiki/Category:Publications_of_M.C._Miller), but for *all groups/authors*. This is a task so huge that it may never be completed, and yet it must take priority over LSIDs, etc....
