On 27/03/2023 01:51, Richard Pyle via Taxacom wrote:
> Taxonomists will always need to publish, because taxonomy is science and science should be published.  The only thing that needs to change is the technical/quasi-legal mechanism of nomenclatural availability.  Except for Code warriors, almost nothing would change.  People would still describe new species in scientific publications.  They would just deal with the technicalities of nomenclatural housekeeping on another platform.
>
> Aloha,
>
> Rich


The only thing that worries me about the above is if authors started to 
decide that publication of their new taxa is no longer necessary once 
they become available purely by registration. There should be some form 
of requirement for publication of the new taxa as well as the 
requirement for registration. If the requirement for actual publication 
of a work is removed from the Code some authors may not bother.
