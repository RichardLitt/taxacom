On Mon, 8 Nov 1999, Doug Yanega wrote:

>The *correct* default setting for mailing lists is what Taxacom has now

Correct only as in the one you prefer, Doug.

I have run enough lists myself to appreciate how complex the tradeoffs
are between setting the default reply-to to the author or to the list.
It is not an easy choice to make.

Personally, I prefer the default reply-to set to the list.  It is more
convenient for most subscribers, and helps to keep discussions going.
But it tends to embarrass people who don't pay enough attention to their
e-mail.  Small lists generally have reply-to set to the list;  big lists
generally have reply-to set to the author.  ECOLOG-L, which Doug Yanega
cited as an example, has been huge for years.  TAXACOM is in the middle.
