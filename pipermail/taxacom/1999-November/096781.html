I have been generating dots on maps for a local web based biodiversity
project and many of the users would query the time component of the dots.
In others words, was the vouchered record used to create the dot collected
yesterday or last century.  So I arbitrarily colour coded the dots from pre
1900 to 1939, 1940-1969, 1970-1999 and No Date Recorded.  Apart from
producing maps that take on a "jelly-bean jar effect", each dot provides a
location and quantified time component which can suggest, at least on
vouchered records only, examples of lack of recent collections or recent
arrivals or local extinctions etc....
