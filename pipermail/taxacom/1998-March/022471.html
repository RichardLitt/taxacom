Well, I guess I set myself up on this one!  I have had so many requests
from people on transferring the mac tiff files to a peecee, that I realized
it would be easier for me to make it easier for them. I found my windows
version of MacBotanica and made a .zip archive of it.  I also changed the
URL for the software.  The old ones still work, but this new one takes you
to a page where you can select which version (Mac or Windows)  to download.

....Botanical Treasures....
The 90 images are all in tiff format, meaning that they are editable 300
dpi bitmaps and can be opened by any word processor or image-processing
program.   The package is freeware, and is freely distributable by any
service, so long as the original archive is not broken into smaller units.

If you like the images and find them useful, drop me an e-mail message at
mfobrien at umich.edu.    The images are available  at: (NOTE NEW URL)
http://www.ummz.lsa.umich.edu/software/   The compressed files take up
about 3 megabytes of hard disk space.

If you  find the files useful, consider making a donation to the Univ. of
Michigan Museum of Zoology.

Cheers,
Mark
