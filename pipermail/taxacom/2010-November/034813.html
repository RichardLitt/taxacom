PDF is a format that is designed to fit the special need of paper 
outprints. If we all agree - as Mike Taylor and others would like to 
see us - that "soon" no scientist will use or need outprints any 
more, then I would predict that PDF would equally soon be outdated, 
and soon not used any more by anybody. In the e-only world there are 
much better file formats available. More interactive file formats. 

I see a contradiction in the arguments here.
