I have used the free NIMAMUSE software package of the U.S.
National Imagery and Mapping Agency for these kind of
conversions. It is available (for several platforms) via
http://164.214.2.59/geospatial/SW_TOOLS/NIMAMUSE/. The DTCC
(Datum Transformation and Coordinate Conversion) program of this
package can convert between geographic co-ordinates, UTM and
MGRS co-ordinates and several national systems (and you can
implement conversions for user systems). NIMA also had a DOS
program called MADTRAN, which might be still available somewhere.

You can find links to other conversion tools at, e.g.,
http://www.helsinki.fi/~rlampine/cartogr.html#conversion.
