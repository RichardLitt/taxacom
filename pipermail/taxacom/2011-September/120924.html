We have not been told about circumstance, but presumably
this was deliberate, for any of a number of reasons. For example,
apparently it is not uncommon to find square brackets being used
when the entire name is in parentheses
http://www.uni-graz.at/~katzer/engl/Prun_dul.html
http://www.jstor.org/pss/2442888
presumably because of some editorial policy about parentheses
within parentheses. If one more set of parentheses were involved
we would be seeing authors within "{...}" brackets.

The answer, of course, being that this sort of publications is not
supposed to be using author citations in the first place,
