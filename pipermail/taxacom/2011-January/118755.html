Dear Niels,

A world map is printed on the inner side of both front and back covers 
of the 1986 book. Unfortunately, the boundaries are shown only down to 
region level. There are several maps in the text (e.g. on page 49) that 
show the province boundaries, but it appears that for many parts of the 
world the boundaries are only described and have never been illustrated.

A Russian (1978) version of the book has been scanned and is posted on 
several websites, e.g. 
http://herba.msu.ru/shipunov/school/books/takhtajan1978_flor_oblasti_zemli.djvu

The last page of this scan contains a color map, showing the boundaries 
down to region level. Interestingly, on some occasions there is a 
difference between the 1986 and 1978 boundaries 
(Circumboreal/Irano-Turanian regions).

If you find a better map or a map that could be used in GIS please let 
me know.

Cheers,

Vladimir
