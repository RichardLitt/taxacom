You are mixing scientific method and irrational absolutism, Mike. Cladistics and molecular systematics involve innocent and powerful tools that can be used to infer descent with modification, and create theories of such descent that can be used in classification. (Classification being the structured language that represents those theories when used to cluster groups evolutionarily.) 

It is the absolutism of using sister-group only analysis that must be condemned as non-science. See more info on this in my Manifesto:
http://www.mobot.org/plantscience/resbot/EvSy/Manifesto.htm
also in Russian:
http://www.mobot.org/plantscience/resbot/EvSy/Manifesto-Russ.htm
for the fun of it.
