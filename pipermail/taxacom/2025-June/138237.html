To put it another way, it does not matter if someone has called something a
nomen nudum. It's a question of whether the description meets the criteria
in the Code or not. Precedent doesn't matter.

Whether something is a nomen dubium is more subjective.

On Wednesday, June 25, 2025, Thomas Pape via Taxacom <taxacom at lists.ku.edu>
wrote:

> Status as nomen nudum depends on specific conditions and cannot (and need
> not) be declared as such by subsequent treatment.
>
> More specifically, in zoology a nomen nudum is a name that, if published
> before 1931, fails to conform to the requirements of the current ICZN Code
> Article 12; or, if published after 1930, fails to conform to Article 13.
>
> Incidentally, note as well that a nomen nudum cannot be "replaced". Only
> an available name can be replaced by another available name, which may be
> an already existing available name, or a new replacement name established
> for this purpose.
>
> /Thomas Pape
