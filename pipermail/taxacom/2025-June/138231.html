I have found out that Fowler's (now "unjustified") emendation of the fish
family Chilodidae to Chilodontidae dates from 1950, so post-dates
Chilodontidae Wenz, 1938 in Mollusca which is presumably why the latter
name is unaffected and is thus an available name; Chilodontidae in Pisces
should therefore arguably be listed as a new name authored by Fowler, 1950
although it is not so in the ICZN Opinion title which reads:

ICZN. (2024). Opinion 2502 (Case 3555) ? Chilodontidae Bronn, 1859
(Ciliophora), Chilodontinae Eigenmann, 1910 (Pisces, Characiformes) and
Chilodontinae Wenz, 1938 (Mollusca, Gastropoda): homonymy between
family-group names resolved.

At present I am keeping my entry for the fish family name in IRMNG as
"Chilodontinae
Eigenmann, 1910" in IRMNG (since that is how I originally acquired it,
based on Eschmeyer's Catalog and elsewhere) but could change it if this is
now considered an incorrect attribution...

Regards - Tony

>> Dear Tony,

>> The statement "Chilodontidae Bronn, 1859 (Ciliophora) is now
>> unavailable" should be incorrect - a name once available remains so
>> (Art. 10.6) unless the Commission has ruled otherwise.
>> Art. 11.7.1 states that a family-group name must meet the criteria "when
>> first published". When the name was established in 1859 the genus-group
>> name was not suppressed. Art. 11.7.1.5 does not come into effect here.
>>
>> Chilodontidae Bronn, 1859 was suppressed, but not ruled to be
>> unavailable. The Commission does usually not rule names to be unavailable.
>>
>> Best wishes
>> Francisco
