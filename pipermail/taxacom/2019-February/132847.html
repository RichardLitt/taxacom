Dear Taxacomers,

I notice that WoRMS is now using "Chilodontaidae Wenz, 1938" for the
gastropod family formerly known as Chilodontidae, that name a junior
homonym of Chilodontidae Eigenmann, 1912, a family of fishes. Several web
sources state that there is a (?recent) ICZN ruling to this effect, but I
cannot find it - if it exists, perhaps someone can point me to it?

As I recall I raised this matter on Taxacom back in April 2010 when I
discovered it, and I believe an application was made to the Commission
following this in 2011 as Case 3555, which according to
http://iczn.org/content/list-open-cases is still open as at time of
writing. So I would be happy if someone could advise whether Chilodontidae
or Chilodontaidae is the "correct" name for the gastropod family at this
time.
