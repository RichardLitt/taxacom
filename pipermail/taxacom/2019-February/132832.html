A zoological name never has a diacritic mark.
The relevant passage in the zoological Code :
   "is deleted, except that in a name published
    before 1985 and based upon a German word,
    the umlaut sign is deleted from a vowel and
    the letter "e" is to be inserted after that vowel
   (if there is any doubt that the name is based
    upon a German word, it is to be so treated)."

Paul
