1993 
A French version of the interactive identification program INTKEY is now
available on the Taxacom FTP server, in the self-expanding file
/pub/software/delta/msdos/intkeyf at .exe. The file must be transmitted in binary
mode, set by the ftp command `binary'. (Failure to do so will result in the
error message `HeaderC Error' when the file is run.)

Place intkeyf at .exe in the same directory as the other DELTA programs on your
MS-DOS computer, and expand it by entering INTKEYF at . This will generate a
French `help' file, INTKEYF.HLP, a batch file INTKEYF.BAT to invoke INTKEY
with this `help' file, and INTKEYF.INI, a slightly modified version of the
sample file INTKEY.INI.

The INTKEY commands themselves have not been translated, so that command-input
files, particularly INTKEY.INI files, can usually be run without translation.
However, the commands could be translated if required.
