1993 
New versions of the DELTA programs for MS-DOS are now available by gopher or
anonymous ftp from the following Internet hosts.

     huh.harvard.edu        (directory: /pub/software/delta/msdos)
     life.anu.edu.au        (directory: /pub/biodiversity/delta/msdos)
     spider.ento.csiro.au   (directory: /delta/msdos)

The Internet distribution package consists of text files *.1st and
self-expanding files *.exe. Download.1st contains this information about
downloading the files, changes.1st contains the revision history of the
programs, and delta.1st describes the procedure for installing the programs on
an MS-DOS computer. The files must be transmitted in binary mode, set by the
ftp command `binary'. (Failure to do so will result in the error message
`HeaderC Error' when the .exe files are run.)

Place the files in the directory C:\DELTA on your MS-DOS computer. Then follow
the installation procedure described in delta.1st, but omit the XCOPY command.

The date of this release is 18 November 1993. The changes from the previous
release (30 September 1993) are as follows.


 DOCUMENTATION

 18 November 1993. The User's Guide was updated to Edition 4.01. The changes
 from Edition 4 are available in the file CHANGES.DOC, and can also be printed
 via DOCPRINT.


 NEW PROGRAMS

 18 November 1993. The following phenetic analysis programs are now included in
 the distribution, in the file DELTAC at .EXE. They work on distance matrices
 produced by the program DIST. They are undocumented, except for brief notes in
 the file CLASS.1ST.

 PCLASS  Agglomerative clustering by combinatorial sorting strategies.
 NSIM    Lists nearest neighbours of taxa.


 TRANSLATIONS

 17 November 1993. An Indonesian vocabulary file for CONFOR (VOCABI), was
 supplied by J. Jarvie, Herbarium Bogoriense, Jalan Juanda 22, Bogor,
 Indonesia.


 DIST

 Version 2.02, 17 November 1993. A directive PHYLIP FORMAT was added.


 ENTITEM

 3 November 1993. A description of some basic TED commands was added to the
 `help'.


 INTKEY

 Version 3.08, 17 November 1993. The error messages for file-access failures
 were improved. The IITEMS file is now not changed when system-defined keywords
 are altered (through invoking a different help file). The use of image-display
 resolutions below 640x480 was removed (to avoid distortion of small images not
 designed for these resolutions). A bug in the output of very small numeric
 values was fixed. A bug in the output of text-mode messages during image
 display was fixed.


 KEY

 Version 2.05, 3 November 1993. Now works correctly when KEY.EXE is on a Novell
 network drive.


 TED

 Version 2.05, 21 October 1993. Safety checks are now disabled during execution
 of commands given on the command line (fixing a problem with ENTITEM).


 TYPSET

 Version 2.04, 16 November 1993. Postscript output lines are now broken only
 between words (avoiding a problem in transferring files between MS-DOS and
 Unix).
