Alexey V. Kuprijanov wrote:

> So, my vote is for a
> balanced approach to the abbreviations. The only problem which for
> ages will remain unsettled is how to convince editors...

I agree. In weed science, in which I partly happen to make my living, a
five letter code is used, which is a combined abbreviation of genus and
species name. For example: Convolvulus arvensis = CONAR, Echinochloa
crus-galli = ECHCG, Stellaria media = STEME etc. With this so-called
"Bayer code" (designed by scientists in the agrochemical branch of the
well-known company) one can unambiguously name all the important weed
species and the system streamlines the extensive tables with data on
numerous weed species often encountered in weed science publications
considerably.
