> From: Claude Godin <godinc at EM.AGR.CA>
> To: TAXACOM

> I would like to know the best (and easiest?) programs to use for
> developing pictorial keys. I need a program (or programs) to draw
> (literally create drawings) AND import scanned images, AND combine all
> this with text and page setup. The resulting document will be printed.

You can find the names of a few drawing and image editing programs in my
'Introduction to computer images', available at
http://biodiversity.uno.edu/delta/ via the link 'Programs and
documentation'. There are many programs for page layout and/or the creation
of HTML documents. A word processor such as MS-Word may be sufficient.

> A program to build interactive computer keys would also be useful.

On the same page (Programs and documentation) there is a link to 'Programs
for interactive identification and information retrieval'. This contains
links and/or contact information for about 25 such programs.

Before selecting an interactive key program, I suggest you look at the link
'Desirable attributes for interactive identification programs' on the same
page.

All these documents are under continual revision, and I would welcome
suggestions for changes or additions.
