On the topic of conceptual baggage hampering communication between people
from the programming community and people from the taxonomy community,
consider:

Class
Order
Natural Key
Name
Concept
Type
Identify/Identification/Identifier
Reference
[...etc...]

Some of these terms have imprecise/ambiguous/homonymous meanings even within
biology (especially "Name"). It always makes for confusing conversations
when a biologist unfamiliar with the IT uses of these terms and a programmer
unfamiliar with the biological uses of these terms get together to discuss
issues related to biodiversity informatics.
