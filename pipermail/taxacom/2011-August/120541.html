I'd like to hear the practices of anyone who is actually using (or
mapping) Darwin Core to represent pollen specimens that reside in a collection
\different/ from the collection from that of the source specimen. Especially:

1. Do you represent the pollen gathering as a different collection
event from that of the source specimen.
2. What do you use to link the pollen specimen to the source specimen
3. If you use any DwC values of the source, do you make any attempt to
synchronize changes to the source record with those of the pollen
record. How?

I really, really, would like to first hear answers from people
currently doing this before people not doing it weigh in on what they
think should be done.

If you have service addresses at which I can fetch some pollen and
source DwC records to study, or have some samples, that would help.
