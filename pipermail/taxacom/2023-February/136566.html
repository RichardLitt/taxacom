> Dear John,
> This must be judged for each case individually along the lines Thomas
> explained. I would not recommend to adopt such a statement and just cite
> the source. A taxonomist should always verify such statements in the
> original literature, as you intended to do that.
>
> The guideline is provided in Art. 33.2. There are two kinds of
> emendations, justified and unjustified emendations, which differ
> substantially in their nomenclatural standing, so it is in any case
> necessary to report which of the two it is.
>
> If the original name must be corrected under the Code (Art. 32.5) then
> the emended spelling is a justified emendation and just counts as the
> correct spelling of that original name - the name is attributed to the
> original author and also takes that date. It is not really necessary to
> cite the author who emended the name, because under the Code such an
> incorrect original spelling must be corrected by anyone who uses that
> name (of course with the exception of those who cite the name for
> documentary purposes).
>
> In all other cases of emendations we are dealing with unjustified
> emendations, and there you need two sources: The original description of
> the name and the source cited for the emendation.
> An emendation differs from an incorrect subsequent spelling in that in a
> case of an incorrect subsequent spelling there is nothing visible in the
> publication itself that the author changed that spelling intentionally.
> Usually the author does not show awareness that the original spelling
> was different.
>
> A "correction" of a Latin or latinized Greek name is an unjustified
> emendation if the author left something visible to show that the change
> was intentional, and it is an incorrect subsequent spelling if the
> publication suggests that the author did obviously not even know that
> the name was spelled differently in the original publication.
>
> If it is an unjustified emendation under this guideline, then that name
> in its unjustified emendation will form a new name with its own
> authorship and date (Art. 33.2.3). This is really serious, it is a new
> name that now comepetes with other names for homonymy. Such names must
> be recorded reliably, and they are important names to be listed in
> nomenclators. Insorrect subsequent spellings can be ignored, but not
> unjustified emendations.
>
> You might have to check a second detail when verifying such cases. If an
> author stated "Aus niger (= brasiliensis Smith, cannot be maintained
> because the species does not live in Brazil)", then some taxonomists
> call this occasionally an unjustified emendation, which it is not. This
> is to be identified as a new replacement name because an emendation
> concerns only the spelling, and niger is not a different way to spell
> brasiliensis.
> The Code is currently silent on the exact limit between an emendation
> and a new name, but we intend to close this gap in the next edition.
>
> If you have difficulties in judging a case, you can send me a link to
> the original description and I can see what I can do.
>
> If this helps.
>
> Best wishes
> Francisco
