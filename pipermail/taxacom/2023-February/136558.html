Dear colleagues,
Oh, my Latin is certainly way worse than my Modern Greek...

My understanding of Art. 11.7.1.1 is that Gorgonopsidae contains the 
stem, so it would formed in agreement with that regulation. Thanks 
Laurent for pointing this out, we should clarify this in Code-5. Should 
read "was formed in accordance with Art. 29".

My statement was this one:

"Gorgonopidae Lydekker, 1890 would be proporly formed under Art. 29.3.1."

I admit that I was talking like a politician. The statement does not 
mean that the spelling Gorgonopsidae has no standing or could not be used.

We seem to have the same problem as we have for species-group names: 
must an original spelling smithi be used if the name was dedicated to a 
woman, and contrasted Art. 31.1? The Code defines such a formation 
definitely as incorrect in Art. 31.1, but in Art. 32.4 provides no means 
to correct such a spelling if it was formed incorrectly in the original 
publication. So the name is incorrectly formed, but not an incorrect 
original spelling to be corrected.

In Code-5 we will have to provide a solution. In the case of dedicated 
species-group names (honorifics) my recommenation is currently to 
maintain the original spelling regardless of being formed correctly or 
incorrectly, and to maintain the spelling with a changed ending if the 
ending was subsequently corrected and that spelling is in prevailing 
usage (and this means, if more than some 85-90 % of the publications in 
the past 50 years have used the corrected ending; we also will need to 
provide a definition how to determine "prevailing usage", and this would 
probably range around such a frame).

Art. 29.1: The cross-reference to Art. 55.3 seems to be in error, this 
should read 29.6.
Art. 29.6 suggests indirectly that forming a family-group name by adding 
the suffix to the entire name of the type genus would be acceptable 
under the Code.

Like in the case of the honorifics we need to consult Art. 32.4 for the 
correction. Art. 32.4 forwards to Art. 32.5.

Art. 32.5.3 regulates in which cases incorrectly formed family-group 
names are to be identified as incorrect original spellings and have to 
be corrected. Basically this Article touches two cases: an incorrectly 
formed suffix, or something was wrong with the spelling of the type 
genus. There is no statement about the stem.

"32.5.3. A family-group name is an incorrect original spelling and must 
be corrected if it

     32.5.3.1. has an incorrectly formed suffix [Art. 29.2], or

     32.5.3.2. is formed from an unjustified emendation of a generic 
name (unless the unjustified emendation has become a substitute name), or

     32.5.3.3. is formed from an incorrect subsequent spelling of a 
generic name [Art. 35.4.1], or

     32.5.3.4. is formed from one of two or more original spellings of a 
genus-group name which was not that selected by the First Reviser [Art. 
24.2.3]."

And this means, no matter if the Code regards a spelling Gorgonopsidae 
directly or indirectly as correct or incorrect, because the entire 
generic name and not its stem was used, Art. 32.4 provides no means to 
correct a spelling based on an incorrect formation in the original 
publication. So the original spelling must not be corrected.

And so Gorgonopsidae would have to be used. If Gorgonopidae would be in 
prevailing usage, then I would recommend to maintain using that 
spelling, otherwise I would currently recommend to stick to the original 
formation.

Sorry not to have researched that immediately. I took a note that in the 
Code-5 revision we will have to look at this.

Tony: do you have an online link to Lydekker 1890 (if possible, BHL)?

Best wishes
Francisco

>> Dear Tony,
>> This follows Code Arts. 29.1 and 29.3.
>>
>> 29.1. Formation of family-group names. A family-group name is formed by
>> adding to the stem of the name [Art. 29.3] of the type genus, or to the
>> entire name of the type genus [see Article 29.6], a suffix as specified
>> in Article 29.2.
>>
>> 29.3.1. If a generic name is or ends in a Greek or Latin word, or ends
>> in a Greek or Latin suffix, the stem for the purposes of the Code is
>> found by deleting the case ending of the appropriate genitive singular.
>>
>> Gorgonops Owen, 1876
>> genitive should be Gorgonopis, stem Gorgonop-
>>
>> So Gorgonopidae Lydekker, 1890 would be proporly formed under Art. 29.3.1.
>>
>> Other examples
>> Merops Linnaeus, 1758 - Meropidae
>> Mormoops Leach, 1821 - Mormoopidae
>> Selenops Latreille, 1819 - Selenopidae
