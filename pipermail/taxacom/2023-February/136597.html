Hi Stephen, your point is taken, however in this particular use case I wish
to distinguish between the various instances of the name "Anura" in my
database, and authorship is the principal method available... so at present
I have:

Anura (previously no authorship, "Dum?ril, 1805" added as a placeholder
just now)
Anura (S.V. Juzepczuk) O.V. Tscherneva, 1962 accepted as Cousinia Cassini
in F. Cuvier, 1827 (Asteraceae)
Anura Agassiz, 1846 accepted as Anoura Gray, 1838 (Chiroptera)
Anura Bellardi, 1873 accepted as Pisanianura Rovereto, 1899
(Littorinimorpha)
Anura Hodgson, 1841 (uncertain) (Aves)
Anura Nicolet, 1847 accepted as Neanura Macgillivray, 1893 (Poduromorpha)

(In this case the first entry is at order rank, the others are genera, but
in course that cannot always be presumed)

So if I want to make a relationship between any other name and a particular
instance of "Anura", I can see which one to choose.

I note that ION also has another name instance, "Anura Fitz. 1843" which I
have not yet investigated further.

It does not bother me too much if "Anura Dum?ril, 1805", "Anura Dum?ril,
1805" and "Anura Fischer von Waldheim, 1813" (or just Anura Fischer,
according to Dubois, since he was not a "von Waldheim" at the time) are all
in circulation so long as they can be recognised as referring to the same
taxonomic entity, however I would like to select one, perhaps according to
the principle of "prevailing recent practice" if not absolute correctness,
for use in my own system - and if justifiable, amend the relevant entries
in Wikipedia and Wikispecies (which currently do not agree with each other)
accordingly.

Regards - Tony
