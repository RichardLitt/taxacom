OK, since Laurent has shown us that the original spelling is Gorgonopidae
(which probably I should have checked for earlier - my apologies for not
doing so), then I guess that should be maintained unless Gorgonopsidae (per
Benton) can be shown to be in prevailing usage by a significant margin,
which it probably can not... therefore I feel safe in going with
Gorgonopidae, and will change the entries in my database to that effect...
unless anyone has suggestions to the contrary of course.

There do seem to have been some side issues thrown up by this discussion
regarding particular articles in the Code which I trust have not been
unhelpful and of course can be discussed further if not yet considered
resolved.
