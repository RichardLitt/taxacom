Hello all (sorry for cross posting),

My Biosystematics course, which requires students to buy the ICZN Code
as a textbook, is larger than I expected this semester, and I need a few
more copies asap.  For a long time the AAZN has kept me with a stock on
hand, which I dole out for a $20 donation to the AAZN, but I will run
out before every student has a copy.  Trying to learn the Code from the
on-line version is quite difficult.

These are things that sometimes pile up with retirements and passings,
so I am wondering if anyone has spare copies laying around they would
like to donate?  I think there are only a very few classes that actually
teach the Code in detail anymore, so there may be few that need those
extra copies.  If you have one and are in the USA, sending a copy by
library rate is really cheap.

Thanks for any help,

Mike
