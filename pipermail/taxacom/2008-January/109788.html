Have a look at the GBIF Mapa application -
http://gbifmapa.austmus.gov.au/mapa/about.jsp
You may be able to adapt it. One of the analysis options it offers is -
"Environment Values Extraction (EVE) - Query a range of environmental layers
(eg climate) using GBIF species record point data to create a table showing
the environmental values at those points. This data can then be used in your
own statistical analyses."
