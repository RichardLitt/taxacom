There seems to be some slippage of meaning going on here. Using distance 
measures does not necessarily amount to using overall similarity. It all 
depends on which diatance is being used. In cladistic analysis, the 
length of a tree can be framed in terms of Manhattan distances, and a 
most parsionious tree is a tree on which that distance is minimal. Does 
that make cladistics a method that maximizes overall similarity? Not if 
you ask me.
