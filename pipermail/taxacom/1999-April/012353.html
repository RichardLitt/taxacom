1999 
The Software Project formerly known as "OZ" is pleased to announce the
public availability of the Beta 2.0 Test Release of the "Specify"
Biological Collections Management System for Microsoft Windows. It can be
obtained from our web site:

        http://usobi.org/specify

This is a test and unsupported version for evaluation only.  Additional
disclaimers are available on the web page and in the Beta User License
Agreement which is part of the installation package.  Please read all of
the accompanying information before downloading and installing Specify.
The first full release is scheduled for June 1, 1999.

We have created an E-mail discussion list with a full-featured web
interface for comments, suggestions and dialogue on the test version.  More
information on the Specify-Beta-Test-L list can be found at
http://usobi.org/archives.

We very much encourage and look forward to your contributions to the
mailing list with your reactions, thoughts and suggestions.

Specify is being developed at the University of Kansas Natural History
Museum with funding from the Biological Research Collections Program of the
US National Science Foundation.

Please address all correspondence to: Ozlab at ukans.edu

The Specify Software Team
