If I understand the Code correctly, a name becomes a nomen nudum only if 
it is presented as the name of a new taxon. If someone claims that a 
genbank name is intended to represent a new taxon, then we have a 
problem. But the act of using an invalid name, without indicating that 
the name is intended to be that of a new taxon, should not be a problem. 
Nevertheless, I would avoid using any name that is not a valid name.
