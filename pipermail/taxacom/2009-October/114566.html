Dear All,

The Centre for Biological Information Technology has just released the newest version of Lucid, version 3.5, which includes a number of new features and enhancements.

Some new features include:

* Natural Language Template Editor
* Entity Descriptions
* Key Reporting Tool
* Bulk Import of Media
* Rotating backups of key data files
* Automatic check for updates
* Player - Manual Discard of Entities
* Player - Get Score
* Numerous miscellaneous enhancements and bug fixes.

For more information visit http://www.lucidcentral.org/Software/Lucid3/Lucidv35Released/tabid/507/Default.aspx
