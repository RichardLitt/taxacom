Hi,

    You can type this command :
contree /tcompress=yes indices=y root=outgroup treefile='C:\Meryta\ITS.tre';
So that you'll have a consensus tree on your display screen which will be 
compress verticaly, rooted with the outgroup you previously give to the 
software, and the last option of the command save the tree on hard drive C 
in a folder (Meryta in this exemple) followed by the name of the tree file 
you want.
    You can then import this tree in TreeView but also import it again in 
PAUP* to do a describe tree.
    Hope that helps.
