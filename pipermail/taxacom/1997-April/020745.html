Greetings,
I would like to announce the release of a new version of my "Orthoptera
DB - The Taxonomy and Collection Manager" program. The new version of the
program is a relational, stand-alone database application, available for
both Windows and Macintosh OS's.
Some of the features include:
- host-guest relationships between specimens and/or species (useful for
people working on parasitoids)
- several user-defined fields
- literature citations manager
- ability to store images and sounds
- powerful, multi-criteria searches, and much more.

I invite interested Taxacomers to visit the database homepage at:
http://viceroy.eeb.uconn.edu/interkey/database.html
