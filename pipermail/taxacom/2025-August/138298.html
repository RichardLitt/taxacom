Dear Taxacomers,

I am working on developing Scratchpads 3.0 in a newer version of
Drupal. The first task is to get the taxonomy importer up and running and
able to ingest the Excel spreadsheets that former Scratchpads users can
obtain through their Scratchpads importer (which is also an exporter).

The first field I will be working on is "Rank". That field did not have all
the needed values in Scratchpads 2.0, and the values could not be edited
due to the rigid implementation of the itis_term_allowed_values function.
That limitation will be solved in Scratchpads 3.0.

Regarding sources of values, the new ITIS data model does include more Rank
values (https://nam10.safelinks.protection.outlook.com/?url=https%3A%2F%2Fwww.itis.gov%2Fdata_definition.html%23rank&data%7C02%7Ctaxacom%40lists.ku.edu%7C05f0f1263eca4cc691f108dde1b0acdc%7C3c176536afe643f5b96636feabbe3c1a%7C0%7C0%7C638914871113810130%7CUnknown%7CTWFpbGZsb3d8eyJFbXB0eU1hcGkiOnRydWUsIlYiOiIwLjAuMDAwMCIsIlAiOiJXaW4zMiIsIkFOIjoiTWFpbCIsIldUIjoyfQ%3D%3D%7C0%7C%7C%7C&sdata=2x5OjPrT5%2F6gk%2ByLyj5b7wZHA2%2F42jx14nWI7zIwxQg%3D&reserved=0). values did you need and did not have? The ranks can be either official
(e.g., regulated by Codes of Nomenclature), or unofficial but present in
the literature.
