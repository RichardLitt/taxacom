I can also confirm the comments by Curtis Clark about Arcview. At my
institution there is a site licence so it cost me relatively little to buy
a basic mapping program (to which I can apparently add others). As
someone who is not a natural computer wizard, the program works
for my purposes in providing map reference data for localities, and I can
also draw tracks and baselines using the mapping facilities of the program.
The only drawback I had in the program I am using is that I could not get
a combined Pacific and Indian Ocean view without having to cut and
past a new base map (evidently the designers of the program did not think
anyone would want such a view).
