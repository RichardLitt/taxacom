OVERVIEW OF WEBPAGE SOFTWARE RESPONSES:

Responses ranged from "do-it-yourself" HTML programming, using free or
inexpensive packages available from the Web, to software programs that can
be purchased, to advice to hire someone.


1) DO-IT-YOURSELF OR VERY LOW-COST PROGRAMS (these require some familiarity
with HTML code):

a) NOTEPAD

b) Allaire Homesite www.allaire.com and HTML Assistant Pro  www.exit0.com

c) NETSCAPE COMPOSER (for an example, go to
http://www.agric.nsw.gov.au/Hort/ascu) - 3 supporters

d) INTERNETCREATOR VER. 4.5

e)  AOLpress from http://www.aolpress.com/

f)  WORDPERFECT and save the file as HTML


2)  SOFTWARE PROGRAMS SPECIFICALLY DESIGNED FOR CREATING WEBSITES

a)  FRONTPAGE - 2 supporters

b)  DREAMWEAVER (for PCs and Macs) - 4 supporters

c)  CLARIS HOMEPAGE (for PCs and Macs) - 4 supporters

d)  HOT DOG PROFESSIONAL (from www.sausage.com) - 2 supporters

f)  ADOBE GOLIVE (for Macs) - 1 supporter

3)  HIRE A PROFESSIONAL, but make sure you can maintain the website.
