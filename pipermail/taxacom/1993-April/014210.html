Peter W.,
To test some printing alternatives, I just downloaded via binary FTP from
huh.harvard, the several asc*.[ps,wp5,ascii] files and printed them.

I printed the diagrams from a DEC Ultrix system (where the files reside)
using "rsh lpr" through the campus network to invoke printing on a
Sun/Unix/NeWSprint system connected to a Sun SPARCPrinter. They printed
just fine. Ditto for the postscript of the main document, except that
something in this chain of events crashed the Sun system part way through
the print job on two of three attempts. The third attempt worked. This,
I believe, was not a problem with the ASC file per se.

I also transferred to, and printed the two diagrams from, a Macintosh, using
the Apple LaserWriter Utility, which comes with the Mac printing system
software. The printer was an Apple LaserWriter IIg. No problem.

I transferred the Wordperfect 5.1 (a DOS application and output file)
directly to the Macintosh as well, and printed it on the same LaserWriter,
using the Mac version of WordPerfect. No problem.

So, as Stan B. indicated in his response, for some systems (different from the
ones that Stan used to produce the doc and diagrams, incidentally), printing
doesn't seem to be a problem.

I didn't try to print the ascii version, but glanced at it online, and it
seems to be intact and not "too wide".
Peter R.
