The New York Botanical Garden has begun the process of hosting specimen data
from other institutions. The GENT (Belgium) herbarium's fungal type
collection is the first set of hosted data to be made freely searchable on
the NYBG web site. All inquiries about the data and specimens should be
directed to Prof. Dr. A. Verbeken (mieke.verbeken at rug.ac.be).

An overview of the catalog and access to the data is located at:
http://www.nybg.org/bsci/hcol/gent/
